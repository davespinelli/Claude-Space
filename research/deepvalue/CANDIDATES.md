## Score formula

```
score = mean of five cross-sectional percentile ranks
          r_fcf_yield   pct-rank of FCF/mktcap            (higher better)
          r_ev_ebit     1 - pct-rank of EV/EBIT           (lower better; NaN or
                                                          non-positive EBIT -> 0.0)
          r_roic        pct-rank of EBIT*0.79/(equity+net debt)  (higher better)
          r_rev_growth  pct-rank of YoY revenue growth    (higher better)
          r_buyback     1 - pct-rank of share-count change (shrinking better)

        a factor whose XBRL concept was simply not tagged scores a neutral 0.5,
        so every company is ranked on the same five factors

        - 0.10 if 6-month return < -40%   (falling-knife penalty)
        + 0.05 if 12-1 momentum > 0       (trend confirmation bonus)

EV        = market cap + long-term debt - cash
FCF       = cash flow from operations - capex
ROIC      = operating income x 0.79 (21% tax) / (equity + LTD - cash)
mktcap    = last close x dei:EntityCommonStockSharesOutstanding
```

## Data notes

- Fiscal periods used per company are in `candidates.csv` (`revenue_period`, `ebit_period`, `equity_period`, `shares_period`). Annual preference CY2025 -> CY2024 -> TTM(4Q) sum of CY2025Q3, CY2025Q4, CY2026Q1, CY2026Q2 for off-calendar fiscal years.
- Balance-sheet instants: first available of CY2026Q2I, CY2026Q1I, CY2025Q4I; prior-year share count from CY2025Q2I, CY2025Q1I, CY2024Q4I.
- `ltd_missing` / `ltd_tag` in the CSV show whether any long-term-debt concept was found and which one. When nothing is tagged, long-term debt is treated as zero, so EV is understated and ROIC overstated for those names. Short-term borrowings, floorplan notes and lease liabilities are never included in EV.
- Cash is `CashAndCashEquivalentsAtCarryingValue`, falling back to the cash-flow-statement total (which includes restricted cash) when the plain tag is absent. Short-term investments and marketable securities are never netted, so EV is conservative for companies that park cash in securities.
- `capex_missing` in the CSV flags companies with no capex concept tagged; for those FCF equals operating cash flow and is therefore overstated.
- Market cap uses the dei cover-page share count, which for dual-class companies sometimes covers only one class and then understates the true market cap.
- Only USD-denominated frames are requested, so foreign-currency filers drop out automatically.
- Sector exclusions use the SIC code from the SEC submissions endpoint, fetched only for companies that already passed the market-cap and liquidity filters.
- No sector-neutrality is applied: the composite is a pure cross-sectional rank, so whichever industry is cheapest on EV/EBIT at the moment can dominate the list (currently: Deep Sea Foreign Transportation of  Freight x5, Pharmaceutical Preparations x4, Services-Educational Services x3).
- One row per CIK: where a CIK maps to several tickers, the class without a `-` suffix (else SEC's file order, which is roughly cap-descending) is kept. Warrants, units, rights and preferreds are dropped by ticker suffix.
