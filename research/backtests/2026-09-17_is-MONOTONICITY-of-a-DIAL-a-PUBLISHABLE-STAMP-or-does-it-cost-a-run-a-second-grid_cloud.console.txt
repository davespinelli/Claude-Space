  CH_ARGMAX  plain IS argmax of the objective                        (the record's habit)
  CH_STAMP   monotone -> refuse the end, fall back to the FROZEN INCUMBENT rung;
             else resolved -> argmax; else -> median rung of the within-1-SD set
  CH_STAMPM  IDENTICAL, except the monotone fallback is the ladder's own MIDPOINT.
             THE FALSIFICATION CONTROL.  CH_STAMP's incumbent fallback is a rung the
             record already chose with hindsight, so any OOS gain CH_STAMP shows is
             confounded with it.  CH_STAMPM knows nothing but the ladder.  If the
             stamp is worth anything, CH_STAMPM must beat CH_ARGMAX too.
  CH_CENTER  always the median rung of the within-1-SD set            (control)
