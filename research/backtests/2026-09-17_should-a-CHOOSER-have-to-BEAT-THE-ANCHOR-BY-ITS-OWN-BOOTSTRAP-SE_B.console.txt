ARM 0 — DATA-FREE.  What IS the R_SE family, before any tape is read?
----------------------------------------------------------------------------------------------------
  R_SE(k) moves iff  d >= k * SE(d),  d = stat(argmax) - stat(anchor) on the IS window.
  Two ENDPOINT IDENTITIES, true by construction and gated below (G5, G6):
    k = 0    -> d >= 0 holds at EVERY decision (d is an argmax minus a member of the
                same ladder), so R_SE(0) moves whenever R_RAW moves: R_SE(0) == R_RAW.
    k = inf  -> no finite d clears it, so R_SE(inf) == R_ANCHOR, 1155's do-nothing.
  THEREFORE R_SE IS A ONE-PARAMETER INTERPOLATION BETWEEN TWO CONTROLS 1154 ALREADY
  PUBLISHED, and its move-rate is NON-INCREASING in k at every basis (G11).  The
  consequence, stated before the result: if the OOS profile is MONOTONE in k, the best
  cell is an ENDPOINT and the SE bar is a DIMMER SWITCH, not a rule.  Only an INTERIOR
  k beating BOTH endpoints would make it a rule.  That is the falsifier this run runs.

  What the bar DEMANDS, per basis, before any tape (the ordering is an identity too):
    SE_IID   ignores serial dependence -> smallest SE -> moves MOST at a given k
    SE_BLOCK L=63 keeps it                                (1101's own resampler)
    SE_FOLD  8 IS calendar years, between-year variance -> expected LARGEST, moves LEAST
  Reported, not assumed: the realised ordering is in the decisions table and Arm B.
