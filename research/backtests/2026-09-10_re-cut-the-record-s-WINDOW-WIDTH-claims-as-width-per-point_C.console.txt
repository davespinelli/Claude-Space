=== PART E  RULE 8 (choose on 2009-2016 only, evaluate 2017-2026 untouched) ===
  WITHIN one sweep the three units are ALGEBRAICALLY the same chooser: on a uniform
  grid the widest run in points, in share and in dial units is the same run, so no
  experiment there can separate them.  The unit can only bite where a width is
  compared ACROSS sweeps -- which is exactly the between-dial comparison PART C
  censused.  So the chooser here is given a MENU of sweeps and must pick one:
    1. take the widest IS-4b window on each sweep in the menu, measured in STATISTIC
    2. adopt the winning sweep's dial, held at that run's midpoint
    3. if no sweep in the menu has an IS window, ABSTAIN to RULES v2 (band .03,
       gross .75) -- abstention is a pick and is scored like every other one
  MENU is a corpus axis, not a third tuned parameter: X1 = the three dials at this
  file's published spacing; ALL = the same three dials at all three resolutions.
