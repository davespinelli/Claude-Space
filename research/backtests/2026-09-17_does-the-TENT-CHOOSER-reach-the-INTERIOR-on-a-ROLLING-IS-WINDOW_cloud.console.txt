# Idea 1161 (cloud lane, 2026-09-17) — does the TENT CHOOSER reach the INTERIOR on a
#   ROLLING IS WINDOW, or only on the ONE-SHOT SPLIT?
#
# 1154: C_IS4B = min(M_S, M_DD, M_CAGR) on the IS window is the ONE non-monotone chooser
#   on the 33-rung gross ladder (a min of two oppositely-sloped monotone legs is a TENT),
#   picked 0.625 (U56) / 0.575 (B136) and was the only chooser clearing 4b full AND OOS.
#   It chose ONCE.  This run re-chooses it on a rolling window and asks whether the
#   interior pick, and the 4b OOS pass, are properties of the CHOOSER or of THAT WINDOW.
#
# TUNED DIALS (2, PROTOCOL rule 4, the two the queue names): WINDOW ['W504', 'W756', 'W1260', 'WEXP']
#   x CADENCE ['R6M', 'R1Y', 'R2Y'] = 12 cells per panel, 24 in all, EVERY ONE PUBLISHED.
#   The gross RUNG is NOT a third parameter: it is the object the chooser selects
#   (1154's framing).  All 33 rungs of both panels are in .grid.csv.
# PANEL {U56, B136} is NOT a dial (both reported everywhere, nothing selected on the pair).
# COMMON SPAN: every cell, control and benchmark scored from bar 1520 (= warm-up 260 + longest window 1260) so the four windows differ in LOOKBACK
#   only, never in scored tape.  These figures are NOT comparable to 1154's full-tape
#   ones (which start at bar 260); 1154's own numbers are replayed in G8 on 1154's span.
# FROZEN: CAND20 legs [(21, 252), (0, 126), (0, 63)], cap INF, max_vol 0.6, min hold 126, N 20,
#   cadence W, cost 10.0 bps (rule 2), LAG 1, warm-up 260, zero cash,
#   block L=63, 1000 draws, crc32 seeds, q=0.9.  PRICE VINTAGE PINNED at 2026-09-15.
#
# DEFINITIONS, DECLARED BEFORE ANY NUMBER:
#   PICK(t) — argmax over the 33 gross rungs of C_IS4B computed on the trailing window
#     ending at bar t (exclusive).  Applied from the NEXT weekly rebalance forward.
#   INTERIOR — pick not in {0.200, 1.000}.  ENDPOINT — either of those two rungs.
#   MOVE — consecutive picks differ.  MOVE RATE = moves / (choices - 1).
#   SWITCH COST — the rolling cell's turnover per year MINUS the same cell's turnover
#     with its gross frozen at the cell's own MEDIAN pick, i.e. the turnover the moving
#     itself adds, in units of NAV per year; times 10 bps it is the drag in bps/yr.
#
# HYPOTHESES, DECLARED BEFORE ANY NUMBER:
#   H_INTERIOR  the rolling tent still reaches the INTERIOR: >= 75% of all choices across
#               all 24 cells are interior rungs.  If it collapses to an endpoint once the
#               window moves, 1154's 0.625 was a property of THAT window.
#   H_STABLE    the pick is UNSTABLE: median move rate >= 0.50 across the 24 cells.  A
#               tent's peak sits where two noisy legs cross, which is the least resolvable
#               place on the ladder (1154 measured the ladder's own Sharpe spread at
#               0.0021 on U56), so the argmax should wander.
#   H_CHEAP     the SWITCH COST is small: median added turnover < 0.50x NAV/yr, i.e. under
#               5 bps/yr of drag.  Gross switching trades only the cash leg.
#   H_OOSPASS   the 4b OOS pass does NOT survive re-choosing at a majority of cells: fewer
#               than 12 of 24 cells clear 4b OOS on the common span.
#   H_NOGAIN    rolling does not beat the frozen incumbent: median (rolling Sharpe -
#               K_FROZEN Sharpe) <= 0 on the common span.
# DECISION RULE, declared before any number: the queue's question is ANSWERED 'YES, THE
#   TENT REACHES THE INTERIOR ON A ROLLING WINDOW TOO' iff H_INTERIOR holds.  It is
#   ANSWERED 'ONLY ON THE ONE-SHOT SPLIT' if H_INTERIOR fails.  Whether that is WORTH
#   ANYTHING is a separate question answered by H_NOGAIN and H_OOSPASS, and a KEEP is
#   asked only on PROTOCOL's own two paths, never on the move rate.
