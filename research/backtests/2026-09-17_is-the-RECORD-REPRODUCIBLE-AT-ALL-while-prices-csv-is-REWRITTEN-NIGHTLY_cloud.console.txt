#   R_NONE        run the gate on the CURRENT file, compare to the committed constant at
#                 the tolerance the record itself declares (5e-5 book, 5e-4 bench).
#   R_TOLERANCE   the same, with every tolerance widened to the observed MAX vintage-
#                 induced spread of that statistic.  Paid in RESOLUTION LOST.
#   R_APPENDONLY  rebuild the tape so no cell is ever restated (every shared cell keeps
#                 its EARLIEST recoverable value; only genuinely new rows append), then
#                 run the gate at the ORIGINAL tolerance.
#   R_FINGERPRINT commit a tape hash beside every constant; the gate re-runs on THAT
#                 vintage, or declares itself UNREPRODUCIBLE.  Paid in bytes per
#                 constant, and it only works if the vintage is IDENTIFIABLE.
#   RESOLUTION LOST — the share of ADJACENT-RUNG pairs on the record's own two ladders

#     genuinely different books a widened gate can no longer tell apart.
#   VERDICT FLIP — a (ladder, rung, path) whose 4a / 4b-full / 4b-OOS verdict differs
#     between a vintage and the CURRENT one.
#
