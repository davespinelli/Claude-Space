  (0a) WHAT A PERFECTLY DEGENERATE LADDER DOES TO A BAR, WITH NO DATA IN IT.
       A ladder whose rungs are IDENTICAL has Sharpe spread EXACTLY 0.  Every ordered
       pair against it is written with it as the NARROWER leg, so M = R_w/0 = +inf and
       V = M/I = +inf.  Then:
         B_RAW    W    (it never corrects)
         B_POINT  W    (+inf > I at every I)
         B_MED    W    (+inf > the null median at every (k_w,k_n))
         B_IID95  W    (+inf > U95 at every (k_w,k_n))
         B_BOOT95 W    (the resampled spread is 0 in EVERY rep, so z = +inf)
       EVERY BAR THE RECORD HAS EVER USED, INCLUDING THE BOOTSTRAP ONE 1214 BUILT
       BECAUSE IT CARRIES THE REAL DEPENDENCE, RETURNS A DECISIVE CALL AT 100% OF THE
       PAIRS A PERFECTLY DEGENERATE LADDER PARTICIPATES IN.  The calls are not WRONG —
       N really is more dispersed than a ladder that is not a dial — they are VACUOUS,
       and they are indistinguishable in a census from calls about real dials.

  (0b) THE DENOMINATOR ARITHMETIC.  Adding one ladder to a set of m ladders adds m new
       ordered pairs and changes NO existing one (a ladder's spread does not depend on
       what it is compared against), so the decisive RATE moves from d/P to
       (d + m)/(P + m) when the new rung is decisive against all m.  For 1214's own
       headline set the arithmetic alone predicts:
         m=3 honest pairs P=3, honest decisive d=0  ->  rate 0.0000 becomes 0.5000
         m=3 honest pairs P=3, honest decisive d=1  ->  rate 0.3333 becomes 0.6667
         m=3 honest pairs P=3, honest decisive d=2  ->  rate 0.6667 becomes 0.8333
         m=4 honest pairs P=6, honest decisive d=0  ->  rate 0.0000 becomes 0.4000
         m=4 honest pairs P=6, honest decisive d=1  ->  rate 0.1667 becomes 0.5000
         m=4 honest pairs P=6, honest decisive d=2  ->  rate 0.3333 becomes 0.6000
       So a set of 3 honest ladders with ZERO decisive pairs reads 0.5000 decisive the
       moment one degenerate rung is admitted, and 1214's 126-of-252 = 0.5000 at ALL4
       is EXACTLY this number.
