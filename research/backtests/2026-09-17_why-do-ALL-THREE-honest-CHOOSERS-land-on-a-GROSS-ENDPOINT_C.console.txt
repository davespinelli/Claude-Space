# DEFINITIONS, DECLARED BEFORE ANY NUMBER:
#   MONO(dial, chooser) — every consecutive difference of the chooser's statistic over the
#     ladder's canonical order has ONE sign (ties allowed).  mono_score = largest share of
#     steps with a single strict sign, so a near-ladder is distinguishable from a jumble.
#   ENDPOINT pick — argmax rung index in {0, R-1}.  INTERIOR pick — anything else.
#   PREMIUM (Q2's answer) — need = best ENDPOINT value - best INTERIOR value, in the
#     chooser's own units.  need > 0 means the interior FALLS SHORT by that much and the
#     chooser would have to see the interior gain `need` to select it.  need/SD is the same
#     figure in units of the PAIRED block-bootstrap SD of that very difference (same draws
#     on both arms, so the tape cancels), i.e. how many noise units the preference is worth.
#
# HYPOTHESES, DECLARED BEFORE ANY NUMBER:
#   H_IDENTITY   MONO => ENDPOINT holds at 100% of monotone cells.  This is an IDENTITY;
#                a failure would mean a code bug, not a discovery.  Bar: 1.000.
#   H_CONVERSE   the converse FAILS: >= 1 NON-monotone (chooser, dial, panel) cell still
#                picks an endpoint.  Endpoint picking is therefore NOT diagnostic of
#                monotonicity, which is what 1150's three-for-three would otherwise suggest.
#   H_GROSSFLAT  on D_GROSS, IS Sharpe is NOT monotone (1150 measured a full-sample Sharpe
#                spread of 0.0016 across the whole ladder) while IS CAGR and IS MaxDD ARE.
#                So C_ISSHARPE's gross-1.00 pick is a FLAT-DIAL NOISE ARGMAX and C_ISCAGR's
#                and C_ISDD's are MECHANICAL — the same pick for two different reasons.
#   H_INTERIOR   at least one (chooser, dial) cell picks the INTERIOR, i.e. endpoint picking
#                is a property of the GROSS dial's shape and not of IS-only choosing.
#   H_UNRESOLVED at the majority of ENDPOINT picks on NON-monotone dials, |need|/SD < 1:
#                the endpoint is preferred by less than one unit of its own noise.
#   H_NOPAY      chooser picks clear 4b at a LOWER rate than the ladders' own base rate
#                (1150: 0 of 48 picks vs 21 of 66 cells).  Rule 8, on five dials this time.
# DECISION RULE, declared before any number: the queue's question is ANSWERED 'YES BUT
#   TRIVIALLY, AND MONOTONICITY IS NOT THE REASON ON THE GROSS DIAL' iff H_IDENTITY holds
#   (as it must), H_CONVERSE holds and H_GROSSFLAT holds.  If IS Sharpe turns out MONOTONE
#   in gross, the three picks have one common mechanical cause and the answer is a flat YES.
#   If H_INTERIOR fails, endpoint picking is a property of IS-only choosing itself and that
#   is a stronger and more troubling answer than the one the queue expects.
