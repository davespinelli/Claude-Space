## Proposal

A steady stream of files into polished Word documents is a template problem before it is a typing problem. If each document is formatted by hand it looks right on the day and drifts within a month, and headings that were typed in bold rather than styled mean no table of contents and no reliable find-and-replace later. Setting the styles once is what keeps batch ten looking like batch one.

Plan:
- Build a Word template first: heading levels, body, tables, headers and footers, agreed with you before any file is converted.
- Convert each source file into that template as real styles, not manual formatting, so the structure survives editing.
- Keep tabular content as Word tables where it belongs in the document, and move it to Excel where you want to work with the numbers.
- Reread each finished document against its source rather than against my own output.
- List anything the source leaves ambiguous instead of inventing a reading for it.

You get the DOCX files, the reusable template, the Excel workbook for the tabular content, and a note of anything I could not reproduce exactly.
