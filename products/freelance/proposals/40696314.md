## Proposal

A partially cleaned dataset is the awkward case. Someone has already fixed the obvious problems, so what is left is the quiet kind: a handful of rows with the wrong sign, dates that parse differently depending on locale, near duplicate customer names, and categories that were merged inconsistently. Those do not look wrong in a cell, they only show up as a total that nobody can explain.

Plan:
- Profile the file and send you a short written list of remaining issues with row counts, before changing anything.
- Fix them as repeatable steps in Power Query, so the same cleaning applies to the next export.
- Build the model: a date table, measures for revenue, units and average order value, and period on period comparisons.
- Build the dashboard pages you need, with filters for period, product and region, and totals that reconcile to the source file.
- Note any row I excluded and why, so no number is unexplained.

You receive the .pbix file, the cleaning steps documented, and the reconciliation note.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/
