## Proposal

You asked for an annual budget workbook in Office 365 that stays easy to maintain. The maintenance part is where most budget workbooks fail: formulas get copied down by hand, someone inserts a row and half the totals stop pointing at the right range, and by month four nobody trusts the dashboard.

Plan:
- Split the file into an input sheet, a lookup sheet for categories, and a dashboard sheet that only reads.
- Build the totals on structured tables and dynamic array formulas so added rows are picked up with no dragging.
- Drive the dashboard from a small set of named ranges, with month and category selectors.
- Add validation on the input sheet so categories and dates cannot be typed freely.
- Write a one page note on where to add data and what not to touch.

You receive the workbook and that note, plus one revision round.

Public example of my reporting work: https://davespinelli.github.io/Claude-Space/
