## Proposal

Four to seven sheets kept up to date is a different job from one sheet typed once. The same value usually lives in more than one of those sheets, and over a few weeks the copies stop agreeing. Nothing in the workbook flags it. Somebody notices when a total is quoted from the wrong sheet.

Plan:
- Map the sheets first and write down which one owns each field, so there is a single source for every value.
- Fix one type per column, dates in one format, numbers stored as numbers rather than text.
- Enter each update against that structure, with a date and source stamp on every changed row.
- Run a cross sheet check after each pass, listing values that disagree between sheets.
- Keep a dated copy before every update so any change can be rolled back.

You get the maintained workbook, the field ownership note, and the check report each round.
