## Proposal

Since the files are digital rather than scanned, the risk is not reading them, it is what the numbers become on the way across. Figures copied out of PDF and Word carry non breaking spaces, thousands separators and a dash that is not a minus sign. They land in the cell looking correct, Excel treats them as text, and every total below quietly leaves them out.

Plan:
- Take one file of each type first and agree the column layout before the rest.
- Pull the text with a parser rather than by hand wherever the file allows it, which removes the transcription error entirely.
- Normalise on entry: numbers as numbers, one date format, negatives as negatives.
- Check totals per file against the source and flag any figure that does not agree.
- Hold anything ambiguous on a query list instead of interpreting it.

Deliverables: the workbook, one sheet per source type, and the query list with file and page references.
