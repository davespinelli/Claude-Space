## Proposal

Budget workbooks from several departments almost never share a line structure. One puts the account code in a merged header, another repeats it per row, a third splits the year across twelve columns. Typed straight into one sheet, the combined totals stop tying back and nobody can say which file the gap came from.

Plan:
- Agree one line schema first: period, department, account code, budget, actual, so every workbook lands in the same shape.
- Map each workbook's columns to that schema once and keep the mapping visible, so you can check my reading of each file.
- Enter each line with a reference back to the file and block it came from.
- Reconcile every workbook's printed total against the lines I transferred from it, which catches a missed block on the spot.
- Flag lines that do not fit the schema instead of forcing them into the nearest column.

You get the combined workbook, the mapping sheet, a per file reconciliation and the queries list.

Proof: my public repo and live pipeline at https://davespinelli.github.io/Claude-Space/

Two questions: how many workbooks and roughly how many lines each, and do they share one layout or one per department?

David

## Delivery plan

3. Days 3 to 4: transfer the lines with source references.
4. Day 5: reconcile each file against its own totals, raise queries.
5. Day 6: apply your answers, deliver the workbook and the reconciliation.
