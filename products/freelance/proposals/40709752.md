## Proposal

Institutional-grade is a claim about evidence, not about the interface. What separates a platform an allocator takes seriously from a screener with a dark theme is that every number on screen reproduces from raw data, point in time, with no look-ahead. I will not pretend this band buys a full platform. It buys the first piece, built the way the rest has to be built.

Plan:
- Build the daily data layer: vendor pull, parquet cache, corporate actions, and a check that flags gaps before they reach a signal.
- Implement one analysis module end to end, the one you rank highest, scored point in time on data available that day.
- Validate it honestly: sample halves, walk-forward, realistic costs, and a written statement of what it does not show.
- Run it on a schedule in CI so the output refreshes without your machine, the way my public pipeline already does.
- Publish the results to a simple dashboard page you own.

You get the pipeline, the module, the validation report and the dashboard, with the source.

Live example of the same pattern: https://davespinelli.github.io/Claude-Space/

Two questions: which analysis module is first, and what data vendor and universe are we working with?
