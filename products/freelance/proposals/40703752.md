## Proposal

Numbers stored as text fail in ways that look harmless until they reach a total. Parentheses and trailing minus signs both mean negative, and a naive strip turns them positive. A comma is a thousand separator in one feed and a decimal point in another. Percent columns are sometimes 12.5 and sometimes 0.125. Blanks, dashes and the string NULL all mean missing but sort differently.

Plan:
- Profile every numeric column across your feeds and list the actual formats found, not the ones expected.
- Write one parser with explicit rules per source: sign handling, separators, currency symbols, units and scale.
- Flag values the rules cannot resolve into a review file instead of guessing or dropping them.
- Add checks that run on each load: row counts, totals against the source, and a share-parsed figure per column.
- Package it as a script or scheduled job you can point at new files without editing code.

You get the cleaner, the per-source rules file, the exception report and a short README.
