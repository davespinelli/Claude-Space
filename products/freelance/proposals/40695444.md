## Proposal

An identical table layout on every page is the good case, because it means the job can be done by rule rather than by eye, and the same script will work on next month's file. The things that still break it are narrow: a row that wraps onto two lines, a column whose values are right aligned so they drift into the neighbour, and the last page where the table stops early.

Plan:
- Extract one page first and send you the result, so we agree the column mapping before the rest is run.
- Write the extraction to the fixed layout, keyed on the column positions rather than on guesswork per page.
- Handle wrapped rows and the short final page explicitly instead of dropping them.
- Check every page: row counts per page, blank cells, and any value that is not the type its column should hold.
- Deliver one sheet with a page number column, so anything questionable can be traced back to its source page.

You receive the Excel file, the check summary, and the script so the next PDF costs you nothing.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/
