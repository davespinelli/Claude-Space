## Proposal

A raw database export usually arrives with formatting rules that were never designed, they accumulated. Each time someone copies a block, Excel splits one rule into dozens covering fragments of a column, the file grows, scrolling stalls, and two cells with the same value end up different colours. The other half is types: dates and numbers exported as text still sort and total wrongly whatever colour they carry.

Plan:
- Strip the inherited rules and record what each one was trying to show before deleting anything.
- Fix the types first, so numbers, dates and text codes are stored as what they are.
- Rebuild a small rule set applied to whole named columns, so it survives new rows and copying.
- Add a header, freeze panes, filters and sensible number formats, so the sheet is analysis ready.
- Write the same steps as a short script or documented routine you can rerun on next month's export.

You get the cleaned workbook, the rule list in plain words, and the rerun routine.
