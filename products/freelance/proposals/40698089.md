## Proposal

A fresh workbook every week is where misalignment starts. Between one week and the next a fund is renamed, two columns swap order, or a fund drops out, and a paste that goes by row position puts last week's fund against this week's number. The figures look fine, the trend is wrong.

Plan:
- Set up one master sheet holding a row per fund per week with the as of date, so history stacks rather than overwrites.
- Map each incoming workbook by fund identifier, not row position, so a reordered file still lands correctly.
- Flag every fund that appears, disappears or is renamed between weeks rather than dropping it silently.
- Check each load for the usual errors: a return typed as 5 instead of 0.05, a missing week, a file loaded twice.
- Derive the summary and cumulative series from that history with formulas, so no figure is typed twice.

You receive the master workbook, the weekly summary, an exceptions sheet and the loader script, so each week takes minutes.

Proof: my public repo and live pipeline at https://davespinelli.github.io/Claude-Space/
