## Proposal

One platform across two divisions is a real build, and the budget here covers a first stage rather than the whole thing. I would rather say that now than quote the full platform and rediscover it in week three. So this bid is for one division end to end, metal trading first, with the data model built so the second division drops into the same structure later.

Plan:
- Agree the ten or so numbers the trading side is actually run on, and where each one lives today.
- Build the ingestion for those sources into one store, scheduled and logged.
- Build the dashboard on top: current position, daily movement, and the exceptions worth acting on.
- Add one agent where it earns its place, drafting the routine summary or flagging outliers for review.
- Keep divisions separated by a tenant field from day one, so adding the second is configuration.

You receive the pipeline, the dashboard, the agent and a README, plus a written scope and price for stage two.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/
