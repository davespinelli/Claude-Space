## Proposal

A form that only produces the right answer when someone clicks the buttons in the right order is a process that stops the day that person is out. It also hides mistakes, because nothing records what was entered, when it ran, or what the button actually produced.

Plan:
- Read the existing workbook first and write down exactly what each button does today, so the automated version reproduces your current output before anything changes.
- Replace the manual entry step with a scripted load from your source file or folder, keeping the sheet layout you already use.
- Run the analysis on one command or a schedule, with the input checked before it is processed.
- Write each run to a dated output, so past results stay available instead of being overwritten.
- Log every run with row counts and any rows the checks rejected.

You receive the automated workbook or script, output from a real run against your data, and a one page runbook.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: what does the button-click processing produce today, and where does the input data arrive from?
