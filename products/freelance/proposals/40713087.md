## Proposal

Mixed regional dates are the one cleanup that cannot be done safely by eye. 03/04/2026 is either 3 April or 4 March, and once a column holds both conventions every sort, every month grouping and every year to date total is wrong without looking wrong. Excel's own conversion makes it worse: it picks one reading and applies it to the whole column silently.

Plan:
- Profile the column first and report back how many rows are unambiguous, how many are not, and which patterns appear.
- Resolve the ambiguous ones with evidence where there is any: order sequence, invoice numbering, or a source file that states its own locale.
- Convert the column to real Excel dates, keeping the original text beside it so nothing is lost.
- Give the same treatment to amounts or text stored as text, which is usually the next problem in the same file.
- Deliver it as a script, so next month's export is one command rather than this job again.

You get the cleaned workbook, a list of every row I could not resolve, and the code.
