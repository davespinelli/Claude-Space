## Proposal

Sales dashboards rarely fail on the charts. They fail on the join: the CRM's revenue and the finance export disagree by a few percent, someone notices in a meeting, and nobody trusts the dashboard again. So I start by making the numbers tie, then build the visuals on top of that.

Plan:
- Take one export of each source and agree the grain with you: what a row is, which date counts, gross or net.
- Write a repeatable Python step that cleans and joins them, with a reconciliation check that flags any row not tying to your own totals.
- Build the dashboard: revenue over time, breakdown by product, region and rep, actual against target, with date and segment filters.
- Add a refresh path so a new export updates it, rather than the whole thing being rebuilt by hand each month.
- One review round on layout and metric definitions.

You receive the dashboard, the cleaning script and a one page definitions sheet, source included.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: where does the data sit today, CRM export, Excel or a database? And do you want this in Power BI, or a browser dashboard you can send a link to?
