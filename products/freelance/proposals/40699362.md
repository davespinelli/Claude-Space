## Proposal

Structured information in a PDF is rarely structured the same way twice. Reference numbers in particular get read wrong, because a zero and a capital O look identical in most document fonts and no reviewer catches it by eye. Every one of those errors is a record you cannot look up later.

Plan:
- Set up the Google Sheet first with the exact columns and a fixed format per field.
- Extract text directly from the PDFs where they carry a text layer, which is faster and more accurate than retyping.
- Type by hand only the pages that are scans, checking each against the source.
- Validate the finished sheet: reference number patterns, date formats, email shape, and blank required fields.
- Return a short list of anything the source itself left ambiguous rather than guessing.

You get the completed Google Sheet, the validation summary, and the query list.

Proof: my public repo and live pipeline at https://davespinelli.github.io/Claude-Space/

Two questions: how many PDFs and roughly how many records each, and are they text PDFs or scanned images?
