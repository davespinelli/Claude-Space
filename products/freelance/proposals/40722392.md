## Proposal

The word "structured" is doing a lot of work here and is worth testing early. A PDF records where each piece of text was drawn, not what it belongs to. A layout that reads clearly to a person, two columns or a table with no ruled lines, comes out of a naive extraction interleaved: the left column's first line, then the right column's, then back again. All the text is there and the order is nonsense, which is harder to catch than a missing page.

Plan:
- Check one file first for real text versus a scan, since that decides the approach.
- Extract by position rather than by stream, so columns, headers and tables keep their reading order.
- Map the repeating blocks to columns once, then run the set.
- Flag every page whose layout does not match the pattern instead of forcing it into the sheet.
- Check counts back, pages in against rows out, plus five files spot checked.

Deliverables: the workbook, the flagged page list, and the extraction script.
