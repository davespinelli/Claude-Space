## Proposal

The Netflix viewing history export is messier than it looks. Episode titles arrive as one string containing series, season and episode, there is no duration column in the activity file, and every profile in the household is mixed into the same rows. Until those are separated, a dashboard shows counts of lines rather than anything about what you actually watched.

Plan:
- Parse the export properly: split series from season and episode, keep films separate, and tag rows by profile.
- Join the billing and device files if you have them, so the timeline is complete rather than activity only.
- Build the views in Plotly: watch time by month and weekday, top series and films, a completion view per series, and a profile comparison.
- Make it a single interactive page with date and profile filters, so it works from a browser without a server to maintain.
- Set it up to accept a fresh export by dropping the file in, so it stays current.

You receive the dashboard, the parsing code, and a README on refreshing it.

Proof: a live dashboard I run in public, https://davespinelli.github.io/Claude-Space/
