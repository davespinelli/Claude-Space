## Proposal

Mixed letter and number codes are the one case where careful typing is not enough. In most document fonts a zero and a capital O are the same shape, as are one and lowercase L, and a reviewer reading by eye will not catch either. On two hundred product codes that is a handful of rows that look right and cannot be looked up later.

Plan:
- Set the sheet up first with one column per field and the code column forced to text, so leading zeros survive.
- Pull the codes out of the PDF rather than retyping them where the file has a real text layer.
- Check every code against the pattern your codes follow, which is what catches an O sitting where a zero belongs.
- Compare the extracted rows back against the PDF page by page.
- Return anything genuinely unreadable as a short query list instead of a guess.

You get the workbook, the check results and the queries list.

Proof of how I work: https://davespinelli.github.io/Claude-Space/
