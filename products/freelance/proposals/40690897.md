## Proposal

Forty five old client files almost never share one layout. Some will have an extra column added years ago, some will have the header on row three, and a few will have totals typed into the middle of the data. Editing them one by one is slow and it is also where mistakes get in, because a change applied to file 12 quietly does not apply to file 31.

Plan:
- Inventory all 45 files first: sheet names, header positions, column sets, row counts, and which ones are the odd ones out.
- Agree with you the exact updates and the rule for each, in writing, before anything is changed.
- Apply the changes with a script so every file gets identical treatment, and keep the originals untouched in a backup folder.
- Produce a per file change report: rows read, fields updated, anything skipped and why.
- Handle the non conforming files by hand and list them separately.

You receive the updated files, the backups, the change report and the script.

Public example of my automation: https://github.com/davespinelli/Claude-Space

Two questions: do all 45 files share the same column layout, and what exactly needs updating in each?
