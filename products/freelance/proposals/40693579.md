## Proposal

If the figures already sit in SQL, the manual submission step is not collecting anything new, it is re-typing data you already hold. That is where the delay and the disagreements between copies come from, so that is the part worth removing first.

Plan:
- Map every field on the current form to the query that returns it, so we agree what is derived and what still genuinely needs a person.
- Replace the manual entry with a refresh that pulls from SQL into the same workbook, on demand or on a schedule.
- Keep the layout your team already reads, so nobody has to relearn the sheet.
- Add validation on the fields people still fill in, and a log of what changed and when.
- Connect through a read only account rather than credentials stored in the file.

You receive the connected workbook, the SQL views behind it, the refresh script and short setup notes.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: which SQL Server version and how do users reach it, and does the workbook need to write anything back or only read?
