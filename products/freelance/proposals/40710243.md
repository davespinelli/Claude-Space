## Proposal

Cleaning and verification are two different jobs, and the second one is where these projects usually stall. Cleaning is rules: trim the whitespace, fix the casing, standardise the spellings, collapse the near-duplicates. Verification means checking a value against something that is known to be right, and that source has to exist before anyone can promise an accuracy figure. If there is no reference to check against, what you can honestly get is internal consistency plus a flagged list of the records that look wrong.

Plan:
- Profile the file first, so we both know the duplicate rate and where the formats disagree.
- Clean with a written rule per field, applied in a script rather than by hand.
- Verify against your reference source where one exists, and flag the rest for your review.
- Report accuracy as a measured number on a sample.
- Leave the rules runnable, so the next batch cleans in one command.

You get the cleaned file, the flagged records, the accuracy sample, and the script.
