## Proposal

Urgent Power BI builds stall on the model, not the visuals. Two weeks in, the charts exist but revenue means something different on each page, period comparison works only where someone wrote it by hand, and the refresh fails quietly overnight. Getting the model right first is what makes the rest quick.

Plan:
- Write down each KPI and its exact definition on day one, since two people rarely mean the same thing by the same metric.
- Build a star schema with a proper date table, so year to date, prior period and rolling windows work everywhere rather than per chart.
- Write the measures once in DAX and reuse them, nothing buried inside a single visual.
- Set up the refresh properly: gateway or cloud source, a schedule, an alert when it fails.
- Review pages with you daily while the build runs, so the urgent version ships first.

You get the pbix file, a documented measure list, the refresh setup and a handover note.

Proof: my public repo and live pipeline at https://davespinelli.github.io/Claude-Space/
