## Proposal

Two automations that touch the same inbox and the same sheet are really one system, and the failure mode is nearly always duplicates: the same email processed twice after a retry, or a row appended again on the next run. Handling that properly at the start is cheaper than reconciling the sheet later.

Plan:
- Write down both workflows as trigger, steps and result, and confirm them with you before building.
- Build on the Gmail and Sheets APIs with a service account, using labels to mark what has been handled so nothing is processed twice.
- Make each sheet write keyed on the message id, so a rerun updates the existing row rather than adding one.
- Run it on a schedule in the cloud, so it does not depend on your machine being on.
- Add an error alert and a small log, so a silent failure is visible the same day.

You get both automations running, the runbook, and access to the code and schedule.
