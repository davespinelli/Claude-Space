## Proposal

Cleaning columns that hold both numbers and text is mostly a question of deciding what each value actually is. "1,200", "1200 " with a trailing space, and "1.2k" should end up as one number. A date typed three ways should end up as one date. The risk is a cleanup that silently rewrites something you meant to keep as text, so I profile first and change second.

Plan:
- Profile each sheet before touching it: column types, blank rates, duplicate rows, and the odd values, and send you that summary.
- Normalise numbers, dates and text casing using rules you approve, not guesses.
- Split or trim combined fields only where the pattern holds across the sheet, and flag the rest.
- Keep the original value in a column beside every changed one, so each change is checkable.
- Deliver a Python script alongside the workbook so the same cleanup runs again next month.

You receive the cleaned workbook, the before and after columns, the script and a short README.
