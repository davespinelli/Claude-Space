## Proposal

A manual entry job is really a checking job. Typing a few thousand fields is the easy half, and re-reading your own work catches almost nothing, because the eye reads what it expected to type. The errors that survive are the plausible ones: transposed digits, a date read in the other convention, a code belonging to a different record.

Plan:
- Key the numeric fields twice and compare the two passes, rather than proofreading once.
- Put validation on the sheet at entry: code lists, a fixed date format, and columns that refuse text where a number belongs.
- Where any part of the source is already digital, move it by script instead of retyping it, and keep the typing for what genuinely needs a person.
- Report the measured error rate per batch rather than claiming a perfect one.
- Keep the originals untouched so any figure can be traced back.

Deliverables: the completed workbook, the validation rules on it, and a per-batch accuracy note.

## Delivery plan
1. Day 1: review a sample of the source, agree the columns, formats and code lists.
2. Day 1: build the sheet with validation before any data goes in.
3. Days 2 to 3: enter the records, scripting whatever part of the source allows it.
4. Day 3: run the second numeric pass and resolve every mismatch against the source.
5. Day 4: report the error rate, hand over the workbook and the originals.
