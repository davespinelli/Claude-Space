## Proposal

The part of a security layout that eats engineering hours is not the judgement, it is the repetition: placing devices to a spacing rule, keeping the schedule in step with the drawing, counting cable runs. A tool saves that time only if its output opens in your CAD as real geometry, on your layers, using your blocks. An image or a separate report means the engineer redraws it. This price covers one drawing type end to end, not a platform.

Plan:
- Pick the highest volume drawing type with you and automate that one completely.
- Read the floor plan from DXF, identify rooms, walls and openings.
- Place devices from your rules on coverage angle, spacing and height, each placement explained.
- Write back to DXF using your own symbol blocks and layer names, so it is editable, not flattened.
- Generate the schedule and cable counts from the same geometry, so the two cannot disagree.

You get the tool, the rules file, a sample output drawing and a README.

A pipeline I run publicly on GitHub Actions: https://davespinelli.github.io/Claude-Space/

Two questions: which CAD package is the source of truth, and can you share three drawings with your block library?
