## Proposal

What decides whether a Sheets tune-up lasts is the boundary between the raw tab and everything built on it. If formulas and formatting sit on the rows people paste into, the next paste shifts a range by one and the summary keeps returning a number that looks fine. Cleanup that leaves that boundary in place gets redone next month.

Plan:
- Keep one raw tab that only ever receives data, and build the clean layer on top of it.
- Fix the types: real dates rather than text, numbers without stray spaces or currency symbols, one spelling per name.
- Replace repeated manual steps with formulas or a small Apps Script, whichever survives you being away.
- Add validation on the columns people type into, so bad values are refused at entry rather than found later.
- Leave a short note on the sheet saying where new data goes.

Deliverables: the tuned file with the original preserved as a copy, and the automation with its trigger set up.
