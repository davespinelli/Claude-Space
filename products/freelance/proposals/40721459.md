## Proposal

The brief describes the dashboard in the past tense, so the first thing to settle is whether this is a rebuild of a file that already exists or the next version of it. Either way, healthcare data carries one constraint that shapes the build: a pbix hands over every row behind the visual, not just the aggregate on screen, so identifiers need stripping or hashing before modelling, not after someone shares the file.

Plan:
- Agree what exists today and what is actually missing from it.
- Check the extract for patient identifiers and de-identify before anything is modelled.
- Build the model in Power Query with the cleaning steps named, plus a proper date table.
- Write each measure in DAX with a one line definition, so readmission and length of stay mean one thing.
- Reconcile the headline totals back to the source extract before handover.

You get the pbix file, the measure definitions and a note on refreshing it.

Proof: https://davespinelli.github.io/Claude-Space/ (Python built, same modelling work, different tool)

Two questions: is this a rebuild or an extension of an existing file, and can you send one sample extract with the columns you hold?
