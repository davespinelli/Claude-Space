## Proposal

When six to ten workbooks come back from a field team with the same simple errors, the errors are usually the same three or four patterns repeated: a date typed as text, a number with a trailing space, a code entered in two spellings. Fixing them by hand in each file leaves no record of what changed. Fixing them once as a script and running it over all ten gives you both the corrected files and a list of every cell it touched.

Plan:
- Read all the workbooks and catalogue the error patterns rather than the individual cells.
- Write the corrections as rules, so the same fix applies consistently across every file.
- Produce a change log naming each file, cell, old value and new value.
- Fix the PDF side alongside it, so the two agree where they should.
- Add validation on the columns the field team types into, so the same errors are refused next time.

Deliverables: corrected workbooks, the originals kept untouched, and the change log.
