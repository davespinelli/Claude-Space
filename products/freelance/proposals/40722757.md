## Proposal

A set of linked workbooks is the part of this worth being careful about. Links hold as long as nobody renames a file, moves it or opens it from another folder. The day one of those happens the formula does not fail loudly, it returns a stale number or spreads #REF through a summary nobody rechecks until month end. So before any figures go in, I want to see how the files reference each other.

Plan:
- Map the workbook links first and list which figures depend on which file.
- Enter the period's transactions into the workbook that owns them, one type per column, dates in one format.
- Replace fragile cross-file references with one input sheet per workbook where that is safe.
- Reconcile before reporting: totals per account and period, and opening to closing balances tie.
- Produce the report from the reconciled figures, with each number traceable to a row.

Deliverables: the updated workbooks, the report, and a one page note on how the files link and what to enter where.
