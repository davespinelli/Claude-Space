## Proposal

Revenue figures moved between workbooks have one test that matters: the new sheet has to total to the same number as the old one, period by period. Most of the errors come from things that look cosmetic. A period labelled Jan-26 in one book and 2026-01 in another, a figure that is negative because it sits in a credit column rather than because it carries a minus sign, and a subtotal row copied in as if it were a transaction, which then double counts.

Plan:
- Agree the target layout once, including how periods, currencies and signs are written.
- Transcribe each workbook into that layout with the source book and sheet kept on every row.
- Reconcile each period back to the source total and show you the comparison.
- Flag anything that does not tie rather than adjusting it quietly.
- Lock number and date formats so later sorting and formulas behave.

You get the consolidated workbook, the reconciliation sheet, and a note of every figure I could not tie.

A pipeline I run publicly: https://davespinelli.github.io/Claude-Space/
