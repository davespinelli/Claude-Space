## Proposal

Your files are a mix of PDFs and Word documents, and those two need different handling. A Word file, or a PDF with a real text layer, can be extracted directly and checked against the source. A scanned PDF has to be read by eye, and the fields that mix letters and digits are where a zero and a capital O look identical. Sorting the pile first is the difference between a workbook that ties out and one that only looks right.

Plan:
- Sort the files into text-layer and scanned, and give you the counts before I start.
- Extract the text-layer files directly so those figures match the source exactly.
- Key the scanned pages, with a second pass over every numeric field.
- Set column types once: numbers as numbers, dates as dates, codes as text so leading zeros survive.
- Report totals and row counts per source file so you can check against the originals.

You get the workbook, a source column on every row, and a list of anything unreadable.

Public pipeline: https://davespinelli.github.io/Claude-Space/

Two questions: roughly how many files and pages, and do you have a target column layout or shall I propose one?
