## Proposal

Consistent layout is true of most of the file set and never all of it. In a batch of fifty there are usually three or four where a table runs onto a second page, a field is absent so everything below it shifts up, or a long value wraps onto the next line. An extractor built on fixed positions handles the other forty six perfectly and drops those four without saying anything, which is worse than failing outright because the sheet looks complete.

Plan:
- Build the extraction against labels and table structure rather than fixed coordinates.
- Run it over every file and produce a per file status, so no document is silently absent from the output.
- Validate each field to its type, with rows failing validation listed rather than blanked.
- Reconcile counts: files in, rows out, fields populated per file.
- Hand over the script so you can rerun it on the next batch yourself.

You get the Excel output, the extraction script with a short README, and the exception list.
