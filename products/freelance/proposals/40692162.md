## Proposal

Your figures already exist and are already correct in Excel. The work is moving them into Word without the formatting quietly changing on the way: thousands separators dropped, one sheet rounding to two decimals and the next to none, a table splitting across a page break in the middle of a row. Retyping solves it once and creates the same job again the next time a sheet is updated.

Plan:
- Agree the target layout from one sample: table structure, headings, number formats, page breaks.
- Write a Python script that reads each Excel sheet and writes the Word document directly.
- Lock number formatting so every sheet renders identically.
- Check every figure in the output against the source and report any mismatch.
- Deliver the Word file plus the script so you can rerun it when a sheet changes.

You receive the finished Word document, the conversion script with a README, and a note on anything ambiguous in the source.

Public example of my pipeline work: https://github.com/davespinelli/Claude-Space

Two questions: how many sheets are in the set, and can you send one sample showing the Word layout you want?
