## Proposal

Pulling text and images from one source into a searchable dashboard is the easy half. What sinks these builds is month two, when the site changes its markup, the scraper fails quietly, and the dashboard keeps showing stale data as if it were fresh.

Plan:
- Build the scraper in Scrapy, storing text plus downloaded images with checksums so reruns do not duplicate records.
- Write output to a database with full text search across the fields you actually search on.
- Build the dashboard: search box, filters, image thumbnails, record detail view and CSV export.
- Schedule it on GitHub Actions with a health check, so a broken selector raises an alert instead of silence.
- Add parser tests against saved sample pages and a README so you can adjust selectors yourself.

You receive the repo, the database, the running dashboard and the schedule.

Live dashboard I built on this pattern: https://davespinelli.github.io/Claude-Space/
