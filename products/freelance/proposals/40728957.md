## Proposal

Re-keying numeric figures has one failure that proofreading does not catch. A transposed pair, 1243 where the source says 1234, is a valid number sitting in a valid column, so it reads correctly on every pass. The only thing that finds it is a figure that has to agree with something else: a column total, a row total, or a control figure carried from the source sheet.

Plan:
- Agree the control totals first, per sheet or per batch, whichever your source gives.
- Key each batch, then reconcile against those totals and clear the differences before moving on.
- Key a sample twice, independently, and compare the passes to measure the real error rate.
- Keep the source layout intact so any figure can be traced back to its original cell.
- Flag rather than guess: anything illegible or ambiguous comes back to you as a list.

Deliverables: the completed workbook, the reconciliation showing each total matching, and the query list.

Two questions: how many sheets and roughly how many figures in total? And do the source sheets carry totals I can reconcile against?
