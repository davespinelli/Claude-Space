## Proposal

Ongoing entry work gets priced as typing time, but the cost that shows up later is corrections: a date entered two ways, a name spelled two ways, a duplicate nobody notices until a total is wrong. Agreeing the rules once and building them into the sheet is what keeps the data consistent whoever is doing the entry that week, including you.

Plan:
- Start with one real batch, so I learn your formats and edge cases rather than guessing at them.
- Set the target sheet up with typed columns, dropdowns on the fields that repeat, and duplicate detection.
- Enter each batch to that structure and return it with a short note on anything ambiguous rather than guessing.
- Where a source repeats in the same shape, a file or a web page, automate that part so it stops costing you per row.
- Agree a weekly rhythm and a turnaround you can plan around.

You receive the structured sheet, the entered data, and the small automations as they arrive.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: roughly how many records a week, and where do they come from, files, email, or a web system?

## Delivery plan
1. Day 1: short call, review a real batch, agree formats and the fields that need validation.
2. Day 2: build the sheet structure, dropdowns, duplicate check and the notes column.
3. Day 3: enter the first batch in full and return the ambiguities list.
4. Day 4: agree corrections, lock the format, set the weekly handover rhythm.
5. Ongoing: each batch returned inside the agreed turnaround, with repeating sources automated as they show up.
