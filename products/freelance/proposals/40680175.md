## Proposal

A descriptive analysis is only as good as what it does with the awkward parts of the data. Missing values, duplicated records and outliers change every mean and every chart, and a report that quietly drops them looks cleaner than the data actually is. I report those first, then the statistics, so you know what the numbers rest on.

Plan:
- Profile every column: type, missing rate, unique values, duplicates, and range.
- Report the data quality issues found and how each one is handled, before any summary statistics.
- Produce the descriptive statistics: central tendency, spread, distribution shape, and frequency tables for categorical fields.
- Chart the distributions and the main relationships, with axes and units labelled properly.
- Write the findings in plain language, with each claim tied to a specific table or figure.

You receive the report as PDF, the charts as image files, and the Python notebook that produced them so the analysis can be rerun.

Public example of my analysis and reporting: https://davespinelli.github.io/Claude-Space/

Two questions: how many rows and columns, and is there a specific question the analysis should answer or is it a general overview?
