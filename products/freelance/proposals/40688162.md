## Proposal

Scraping that breaks on Indian marketplace listings is usually not a code problem. Sellers describe the same OEM part five different ways, so exact matching finds nothing and fuzzy matching produces false positives you cannot put in a catalogue.

Plan:
- Start from a sample of your current SparePe rows and the listings that failed, and find where the match actually breaks.
- Normalise part numbers and brand strings (separators, prefixes, OEM versus aftermarket suffixes) before any comparison.
- Score each candidate on part number, brand and vehicle fitment together, then set a confidence cut so doubtful matches go to a review queue instead of the catalogue.
- Deliver verified rows as clean CSV with a confidence column and the source URL behind every match.
- Package it as a rerunnable Python script so the next batch costs you almost nothing.

You receive the verified dataset, the script and a short README. I work from publicly visible listing pages only.

Example of my Python data work: https://github.com/davespinelli/Claude-Space
