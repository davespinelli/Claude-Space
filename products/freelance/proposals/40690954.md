## Proposal

Two hundred pages of numerical data going into one master workbook has a specific failure mode: the numbers arrive fine but nobody can prove they arrived fine. If page totals are not reconciled against the workbook, an error in the middle can sit there for months. So I treat the totals as the checksum rather than as an afterthought.

Plan:
- Extract the numbers page by page, keeping a page reference on every row so any figure can be traced back.
- Normalise formats: thousands separators, negatives in brackets, currency symbols, and dates.
- Reconcile each page total and each column total against the source, and report any page that does not tie out.
- Build the master workbook with one consistent header row, no merged cells, and a raw sheet kept separate from any summary.
- Deliver the extraction script so the same process runs on the next batch.

You receive the master workbook, the reconciliation report and the script.
