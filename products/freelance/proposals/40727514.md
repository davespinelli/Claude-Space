## Proposal

The usual export does not give you the layout you want because Excel sets page breaks from column widths, not from your data. It splits a record across two pages, drops the header row after the first page, and shrinks one sheet while leaving the next full size. Fixing that by hand works once, then next month's workbook arrives and it is all redone.

Plan:
- Set the print area, orientation and fit-to-width scaling per sheet, so each one prints at a consistent size.
- Repeat the header rows on every page, and set page breaks on group boundaries so a record is never split.
- Export only the sheets you name, either to one combined PDF or one file per sheet.
- Deliver it as a script you run on next month's workbook, with page numbers and the sheet name in the footer, not a one-off manual export.

Deliverables: the PDF output, and the script or macro that produces it.
