## Proposal

Fake news classifiers usually report high accuracy and then fail on anything outside the dataset they were trained on. The reason is that the public datasets carry style artefacts, so the model learns the source rather than the claim. The honest fix is not a bigger model, it is a test split held out by source and by time period, so the reported number reflects unseen material.

Plan:
- Load and clean the dataset, check the class balance and remove duplicate and near duplicate articles.
- Baseline first with TF-IDF and logistic regression, so there is a number the model has to beat.
- Train a transformer classifier, and evaluate on a split held out by source and date rather than at random.
- Report precision, recall, F1 and the confusion matrix per class, plus the most influential features.
- Deliver an inference script that scores a new article and returns the label with a confidence.

You receive the training and inference code, the trained model, the evaluation report and a README.
