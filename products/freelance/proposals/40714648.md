## Proposal

Spreadsheets holding text and numbers in the same columns almost always arrive with the numbers stored as text. That is why totals come out short and sorting puts 10 before 9. Retyping by hand fixes the rows you can see and leaves the format problem exactly where it was.

Plan:
- Profile every sheet first and report what is actually in each column, including cells that only look numeric.
- Agree one target layout with the text and numeric fields properly separated.
- Convert with a script, so the same rule lands on every row instead of row by row judgement.
- Trap the rows that will not convert cleanly and list them for your decision rather than guessing.
- Compare row counts and column totals before and after, so nothing goes missing in the move.

You receive the consolidated workbook, an exceptions sheet listing every row that needed a decision, and the conversion script for future files.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/
