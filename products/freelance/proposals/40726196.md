## Proposal

A report generator built straight onto a ledger export breaks the first month someone inserts a column or renames an account. Monthly ledgers and balance sheets almost never arrive in exactly the same shape twice, so the tool has to read them by header and account code rather than by cell position, and say plainly when something it expected is missing.

Plan:
- Map the fields the tool needs from your ledgers and balance sheets, keyed by header, not position.
- Load each month into one tidy table with real dates, real numbers and one spelling per account.
- Check it before reporting: totals tie back to the source, and anything unmapped is listed rather than silently dropped.
- Generate the report itself, with the period comparisons and ratios you actually review.
- Package it so you run it on next month's files with one command and no editing.

Deliverables: the generator with its source, a sample report from your own data, and a short README.

Proof: https://davespinelli.github.io/Claude-Space/
