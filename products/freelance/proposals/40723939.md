## Proposal

Sales, survey and financial data rarely share a key. Sales is one row per order line, survey is one row per respondent, finance is one row per month. A workbook that imports all three into one place and offers to analyse them together will happily produce a chart that compares numbers which do not belong on the same axis. The structure has to decide the common grain before any formula is written.

Plan:
- Set the grain first: which period and which entity all three sets roll up to.
- One import tab per source, untouched by formulas, so a refresh is a paste and not a repair.
- A mapping layer that turns each source into that shared grain, with unmatched rows shown rather than dropped.
- Measures and a summary built only on the mapped layer.
- A checks tab that reports row counts in and out, so a short import is visible immediately.

Deliverables: the workbook with the three import tabs, the mapping and summary, and a note on refreshing each source.
