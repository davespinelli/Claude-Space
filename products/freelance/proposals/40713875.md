## Proposal

Voice agents usually break at the handoff, not the conversation. The agent takes the call fine, then the booking does not appear in the calendar, the CRM record is missing, or the transfer to a human drops. That integration layer is where the work is, and it is the part nobody tests.

Plan:
- Write down the call flows you want, with the exit condition for each: booked, transferred, voicemail, or no fit.
- Build the Retell agent config and the webhook backend that receives each call event.
- Wire the outcomes into your calendar and CRM, with retries and a dead letter log so a failed write is visible rather than lost.
- Replay recorded or scripted calls against it and report the completion rate per flow.
- Hand over the config, the backend and a note on how to change prompts safely.

You get the agent setup, the integration backend, the test results and the source.

Pipeline I run in public: https://davespinelli.github.io/Claude-Space/

Two questions: which calendar and CRM are on the other end, and is this inbound, outbound or both?
