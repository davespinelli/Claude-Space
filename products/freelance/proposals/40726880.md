## Proposal

A batch of PDFs and scanned images is really two jobs. Native PDFs carry their text, so the values can be pulled exactly and checked against the page. Scans have to go through OCR, where digits like 1 and 7 or 0 and 8 are where the errors hide. Treating both the same way is how a clean looking sheet ends up with wrong numbers in it.

Plan:
- Sort the batch into native PDFs and true scans, and handle each with the method that suits it.
- Extract the native ones by text, so those values are exact rather than read.
- Run OCR on the scans, then check every numeric field by eye against the page image.
- Load everything into one workbook with consistent headers, real dates and real numbers.
- Flag anything unreadable in its own column with the source file and page, rather than guessing.

Deliverables: the finished workbook, plus the flagged list of anything I could not read with confidence.
