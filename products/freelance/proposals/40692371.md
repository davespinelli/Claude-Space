## Proposal

Batches arriving as Excel, Google Sheets and the occasional PDF is the part that makes this ongoing work rather than a one off. Each format loses something different. Excel turns reference numbers into numbers and drops leading zeros, Google Sheets exports carry stray formatting, and a PDF table has no columns at all until something reconstructs them. Handled by hand, every batch takes as long as the first one.

Plan:
- Agree one target schema for the entries, whatever format a batch arrives in.
- Build a Python intake that reads xlsx, a Sheets export and PDF tables into that same schema.
- Preserve text fields as text so reference numbers and codes survive intact.
- Validate each batch: required fields present, dates parseable, duplicates against what is already loaded.
- Return an exceptions list per batch so you approve corrections instead of finding them later.

You receive the loaded sheet, the intake script and a short runbook for the next batch.

Live example of a pipeline I run: https://davespinelli.github.io/Claude-Space/
