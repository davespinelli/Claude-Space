## Proposal

A PDF either carries a real text layer or it is a picture of a page, and which one you have decides whether this is a conversion job or a retyping job. There is a third case that causes most of the trouble: exports that preserve the look by wrapping every line in its own text box. Those open in Word and read as faithful until you try to edit a paragraph.

Plan:
- Check each file for an extractable text layer and tell you which ones have it before any work starts.
- Rebuild those files in Word as real paragraphs, headings and styles, not floating boxes.
- Retype or OCR and proof the scanned pages, then read each against the original line by line.
- Move the tabular pages into Excel as typed columns, one sheet per table, with the source page noted.
- Return a short list of anything ambiguous in the original rather than guessing at it.

You get the DOCX files, the XLSX workbook, and a note of any page I could not reproduce exactly and why.

Work I run in public: https://davespinelli.github.io/Claude-Space/

Two questions: how many pages in total, and are any of the PDFs scans rather than digital exports?
