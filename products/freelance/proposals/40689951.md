## Proposal

Budget workbooks are the case where a transcription error is expensive and invisible. Every line looks plausible on its own, so a digit dropped in one department shows up only when a total is off by an amount nobody can trace. Multiple workbooks make it worse: cost centre names drift between files and the same line ends up under two labels.

Plan:
- Review your workbooks and agree the target layout: period, cost centre, line item, budget, actual.
- Build a consistent cost centre and line item list first, so the same thing is named the same way everywhere.
- Transfer every line, keeping the source workbook and sheet on each row so any figure can be traced back.
- Reconcile: totals per workbook and per cost centre must match the source before I hand anything over.
- Flag lines that do not reconcile rather than adjusting them, and go through that list with you.

You receive the consolidated workbook, the reconciliation tab and the exceptions list.

Public example of my work: https://github.com/davespinelli/Claude-Space
