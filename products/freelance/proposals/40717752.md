## Proposal

Form notifications arriving as email have one failure mode that careful typing does not fix: a missed email leaves a gap in the sheet, and nothing in the sheet shows the gap is there. Reading the mailbox directly fixes it, because every message carries an id and the sheet can be checked back against the mailbox.

Plan:
- Take three or four sample notification emails and map every field you want into columns.
- Read the mailbox over IMAP or the Gmail API, filtering to the sender and subject pattern of the notifications.
- Parse each message into a row, keeping codes and phone numbers as text so leading zeros survive.
- Write to the spreadsheet, skipping messages already recorded so re-runs never double up.
- Report each run: messages seen, rows written, and any message that did not parse.

You receive the script, the spreadsheet, a short README, and the option to run it on a schedule so new submissions land on their own.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/
