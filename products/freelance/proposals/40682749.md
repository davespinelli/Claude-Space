## Proposal

High volume Display campaign creation breaks down in the repetitive middle: building ad groups, uploading assets in every required size, and setting targeting identically across dozens of campaigns without a single typo.

Plan:
- Define a campaign as a structured spec file (sheet or YAML), so a campaign becomes data rather than a sequence of clicks.
- Build the automation against the Google Ads API rather than the UI, so it is reliable, auditable and rerunnable.
- Use Claude to generate headline and description variants from your brief, with a validation pass on character limits and policy sensitive wording before anything uploads.
- Create everything as drafts or paused first, with a diff report of what will be built, so a human approves before any spend starts.
- Add logging, retries and safe reruns that do not duplicate campaigns.

You receive the repo, the campaign spec template, a runbook and a walkthrough.

My public repo showing this style of scripted pipeline on GitHub Actions: https://github.com/davespinelli/Claude-Space
