## Proposal

Files that share a layout still break in two predictable places: a table that splits across a page, and an optional field that is absent on some documents rather than blank. Both produce a row that looks correct and is quietly shifted by one column. That is why the extractor has to be written against your real files rather than a template, and why every row should carry the file and page it came from.

Plan:
- Start from five files that cover the range, including the ugliest one you have.
- Write a Python extractor keyed on the labels in the document rather than on fixed coordinates, so small shifts do not break it.
- Handle tables that continue onto a second page, and missing optional fields, explicitly.
- Output one Excel sheet with a source file and page column on every row.
- Run the full set, review the exceptions with you, and hand over the script so the next batch costs nothing.

You receive the script, the Excel output, an exceptions list and a short README.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: are the PDFs text based or scanned images, and roughly how many fields per document?
