## Proposal

Keeping workbooks current with fresh figures is a different job from building them. The risk is not typing speed, it is that each update overwrites the last with no record of what changed, so when a number looks wrong three weeks later there is nothing to compare it against. The second risk is a pasted figure landing in a cell a formula depends on.

Plan:
- Run one cycle by hand first, so I learn exactly where each figure lands and what a normal value looks like.
- Keep a dated copy of every workbook before the update, so each change is traceable.
- Add a validation pass: missing cells, figures outside their usual range, and figures that did not move when they should have.
- Leave your formulas, formatting and sheet structure untouched.
- If the figures come from a source I can read directly, script the collection so later cycles take minutes.

Deliverables: the updated workbooks, a change log per cycle, and the collection script if the source allows one.
