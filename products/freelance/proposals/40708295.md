## Proposal

Portfolio dashboards usually look right and are wrong in exactly one place: the return number. Deposits and withdrawals get counted as performance, a split or a dividend moves the cost basis and nothing reconciles after that, and the equity curve keeps drawing a line nobody can tie back to the broker statement.

Plan:
- Load positions and transactions from your broker export or API, whichever you already have.
- Compute cost basis, realised and unrealised P&L, with cash flows separated so the return is time weighted rather than flattered by deposits.
- Refresh prices daily and store the pull time, so stale data shows on screen as stale instead of looking flat.
- Dashboard: holdings table, allocation, equity curve against a benchmark, and contribution per position.
- Deploy on a schedule with a README and the source.

You get the data layer, the dashboard and the source.

Dashboard I run in public, rebuilt daily by GitHub Actions: https://davespinelli.github.io/Claude-Space/
