## Proposal

The word doing the work in your brief is "supposedly". At 23,000 SKUs a UPC column is never simply right or wrong. It holds blanks, codes that fail their check digit, codes that lost a leading zero when Sheets read them as numbers, and the same code on two rows. Fragrance makes that worse, because one scent exists in several sizes and each size carries its own UPC, so a code on the wrong size looks perfectly valid.

Plan:
- Score every code on length, check digit, leading zero loss, and duplication across SKUs.
- Separate blanks from wrong codes, since those are two different fixes with different costs.
- Cross check title plus size, to catch codes that belong to another size of the same fragrance.
- Write the audit into a tab with one flag column per test, so you can sort and work it.
- Deliver it as a script that reruns on the sheet as it grows, not a one-off cleanup.

Deliverables: the audited sheet, the flag definitions, and the script.
