## Proposal

A backlog of patient files digitised by hand gives you a workbook you cannot check. Dates arrive in three formats, the same person appears twice under two spellings, and nothing records which file a row came from. I key the fields the same way either way, but I add a source reference to every row so any value can be traced back to the file it came from.

Plan:
- Agree the column list from three or four sample files before any bulk work starts.
- Normalise dates to one format and keep ids, phone numbers and postcodes as text so leading zeros survive.
- Flag suspected duplicate patients for your review rather than merging them silently.
- Record the source file and page against each row.
- Return a short list of anything unreadable instead of guessing at it.

You receive the workbook, a data dictionary for the columns, and the exceptions list.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: are the files typed or scanned, and how many patients are in the backlog? If any are handwritten I will want samples before quoting that part.
