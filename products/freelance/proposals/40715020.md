## Proposal

Survey responses are easy to type and hard to use afterwards. Three people give the same answer in three wordings, and by the time you want to count them the spreadsheet cannot group anything. Fixing the answer categories before entry starts is what makes the data countable later, and it costs nothing to do up front.

Plan:
- Agree the column layout and a fixed set of allowed values for every closed question.
- Load the responses, keeping each raw answer beside its coded value so nothing is lost.
- Enter free-text answers verbatim, with a separate tag column you can filter on.
- Validate as I go: required fields present, dates real, no duplicate respondents.
- Finish with a one-page count per question so you can see the shape of the results.

You receive the completed spreadsheet, the validation log showing what was queried, and the loader script if more responses arrive later.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/
