## Proposal

Charts that update automatically as rows are typed in come down to one decision made early: the data has to live in a proper Excel table, not a fixed range. A chart pointed at A2:D500 stops growing the moment someone types into row 501, and it fails silently, so the sheet keeps looking correct while the picture behind it has stopped moving. Structured table references plus dynamic named ranges fix that permanently, with no macro to enable and no refresh button to remember.

Plan:
- Put the entry data in one structured table with typed columns and validation on the fields people mistype.
- Build the charts and PivotCharts off that table so new rows are picked up on entry.
- Add slicers and a date filter so you can cut the view without editing anything.
- Add a small checks block: row count, blanks, out-of-range values, last entry date.
- Protect the layout so the entry sheet is the only editable area.

You receive the workbook, a one-page note on adding fields later, and one revision round.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/
