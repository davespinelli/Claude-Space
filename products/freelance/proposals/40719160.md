## Proposal

A trending script that works today and breaks next month is the usual outcome here, because most of them scrape the web app and the web app changes. I would build it against TikTok's official endpoints, the Research API or the Creative Center trending feeds, which are public, documented and do not require anyone's login. It is a little more setup and it keeps running.

Plan:
- Confirm which official access you qualify for, and fall back to the public Creative Center feeds if not.
- Pull trending videos by region and period into a dated CSV or SQLite file.
- Capture the fields worth having: video id, url, author, caption, sound, view and engagement counts, timestamp.
- De-duplicate by video id, so daily runs build a history instead of repeating rows.
- Add retries, rate limiting and a per-run log, and put it on a schedule if you want it unattended.

You receive the script, the data file, a README and the schedule setup.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: which regions do you need, and do you want video files downloaded or only the metadata and links?
