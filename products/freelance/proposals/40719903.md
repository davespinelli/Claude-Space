## Proposal

A working script usually gets posted here because the run stopped finishing, not because nobody has Python. The usual causes are a changed page layout, a rate limit that returns empty pages instead of an error, and a run that dies halfway and restarts from row one. So I would treat this as run it and tell you why it failed, rather than hand back whatever comes out.

Plan:
- Run your script as written in a clean environment and record what it produces.
- If it breaks, find the real cause and send you a short note with the fix. 
- Add resume from the last completed row and a run log, so a long run survives a restart.
- Deliver the output as CSV with a row count and the sources that came back empty.

To be straight with you: I run it at a polite rate from an ordinary host, and I will not add proxy rotation or captcha solving if the sites are blocking it. If that is the blocker I will say so.
