## Proposal

Moving paragraphs out of Word into Excel usually breaks in one place: deciding where a row ends. A paragraph that wrapped across two lines becomes two rows, a heading becomes a stray row, and the header that repeats on every page ends up scattered through the sheet. Copy and paste cannot tell those apart, but a script reading the document structure can.

Plan:
- Extract paragraph text with python-docx, keeping document order and the source file name.
- Set row boundaries on paragraphs, not line breaks, so wrapped text stays in one cell.
- Add columns for source file and paragraph number, so any row can be traced back.
- Drop empty paragraphs and repeated headers and footers, and flag anything ambiguous rather than guessing.
- Write one workbook, one sheet, plus a short log of what was removed and why.

You receive the workbook, the conversion script so a rerun costs nothing, and that log.

Public example of my automation running on a schedule: https://github.com/davespinelli/Claude-Space

Two questions: should headings and any text inside tables be included, or body paragraphs only? And do you want one row per paragraph or one row per document?
