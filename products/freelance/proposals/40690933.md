## Proposal

Filling a form record after record from a spreadsheet is straightforward to automate. What decides whether it is actually useful is what happens on record 47 when a dropdown has no matching option, or the page is slow, or the submit silently fails. A script that stops there and tells you which row it stopped on is worth far more than one that races through and leaves you unsure what landed.

Plan:
- Read the sheet with pandas and validate every row against the form fields before the browser opens.
- Drive the form with Selenium using stable selectors, waiting on elements rather than fixed sleeps.
- Confirm each submission from the page response, and write the result back next to the row.
- Retry transient failures once, then park the row in a failures tab with the reason.
- Make the run resumable, so restarting does not resubmit rows already done.

You receive the script, a config file for the field mapping, the run log and a README.
