## Proposal

Several Excel and CSV files with mixed text and numeric fields almost never merge cleanly. Numbers arrive stored as text, dates come in three formats, and the same field is called something different in each file. Typing it across by hand hides those problems instead of fixing them.

Plan:
- Inventory every file and column, then agree one target layout for the combined sheet.
- Script the consolidation in Python so text and numeric fields are typed correctly, not left as strings.
- Normalise dates, trim whitespace, standardise the categories that appear under different spellings.
- Flag duplicates and blank required fields on a separate review tab rather than silently dropping them.
- Deliver the combined workbook plus the script, so the next batch takes minutes.

You receive the clean consolidated file, the exceptions tab, and the reusable script.

Example of my data pipeline work, public repo with tests: https://github.com/davespinelli/Claude-Space
