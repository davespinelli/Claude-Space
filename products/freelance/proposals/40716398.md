## Proposal

You asked for clean, fully verified records, and that word is the whole job. Scraped Maps results go stale and duplicate fast: the same business appears twice under two spellings, a third of the phone numbers are formatted four different ways, and closed locations stay on the list. Google's terms also prohibit scraping Maps pages, and scraped output carries no source you can point at later. I would pull the same fields through the official Places API instead, which returns a stable place id per business, so every row is traceable and re-checkable.

Plan:
- Agree the categories and the exact geographies, then grid-search each area so dense city centres are not truncated.
- Pull name, address, phone, website, category, rating, review count and place id.
- Deduplicate on place id, normalise phone and address formats, drop permanently closed entries.
- Flag rows missing a phone or website rather than quietly shipping blanks.
- Deliver as CSV and Excel, with a per-area row count so coverage is visible.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: which categories and cities, and do you have a Google Cloud billing account, or should the API cost come out of this fee?
