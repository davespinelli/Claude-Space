## Proposal

Fund pages are the kind of source that fails quietly. NAV posts once a day, the table layout changes without warning, and a scraper that returns yesterday's figures or an empty sheet looks exactly like one that is working. So the part worth paying for is not the pull itself, it is finding out the same morning when a source stops answering.

Plan:
- Agree the exact sites, funds and fields on a short call, and save one page from each as a reference copy.
- Write one small Python collector per site, publicly accessible pages only, nothing behind a login.
- Write each run into Excel with an append-only history sheet, so restated figures stay visible instead of overwriting.
- Check every run for missing funds, stale dates and impossible values, and flag it when a check fails.
- Schedule it to run daily without your machine being on.

You receive the collectors, the Excel output, the run log and a short README.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: which sites and roughly how many funds, and do you want one file per day or a single workbook that grows?
