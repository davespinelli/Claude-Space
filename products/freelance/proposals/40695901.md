## Proposal

Records that mix numbers and text are where Excel does the most quiet damage. A reference like 0012 loses its leading zeros, a code such as 3E5 becomes scientific notation, and anything that resembles a date gets converted on the way in. Transcribing accurately means controlling how each column is typed before the first value lands, not correcting cells afterwards.

Plan:
- Agree the column list and set each one to text or number explicitly, so nothing is auto converted.
- Transcribe every line, keeping identifiers and codes exactly as written in the source.
- Run checks after entry: row count against the source, blank required fields, duplicates, and values that do not match their column type.
- Send you an exceptions list for anything ambiguous in the source rather than deciding for you.
- Deliver the file in your layout, with a second sheet holding the checks so the accuracy is visible.

You receive the completed workbook, the checks sheet, and the exceptions list.

Proof: my public repo and live pipeline at https://davespinelli.github.io/Claude-Space/
