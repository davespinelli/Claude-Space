## Proposal

The risk in a hand built research dataset is not speed, it is that nobody can tell later where a given cell came from. Two people capture the same field from different pages, the numbers disagree, and the whole set has to be re-checked because there is no source trail.

Plan:
- Agree the schema first: every field named, typed, and with a rule for what counts as missing.
- Capture each record with its source URL and the date it was read, stored alongside the data.
- Run validation as we go: ranges, formats, duplicate keys, and anything that fails gets flagged rather than guessed.
- Sample check a fixed percentage of finished records against the source and report the error rate.
- Deliver as Excel and CSV, plus the capture rules written down so a second pass matches the first.

You get the dataset, the source column, the validation report and the schema note.

Pipeline I run in public: https://davespinelli.github.io/Claude-Space/

Two questions: roughly how many records, and are the sources open pages or anything behind a login or paywall? I only work from publicly accessible sources.
