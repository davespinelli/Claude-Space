## Proposal

Copying between files goes wrong at the joins rather than in the typing. The same field is named differently across two source files, dates arrive in two formats, and one block gets pasted twice. None of that shows up while you are working, only later when you try to use the sheet and the numbers do not agree.

Plan:
- List the source files and map every field to one column name in the destination.
- Extract rather than retype wherever a file carries a text layer, which removes typing error entirely.
- Normalise dates and numbers to a single format on the way in.
- Check for duplicate and missing rows against the source counts, not by eye.
- Hand review the flagged rows, then hand over with the reconciliation attached.

You receive the completed Excel and Word output, a reconciliation sheet showing source rows against delivered rows, and the script so any later batch takes minutes.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: how many source files and roughly how many rows in total, and is the destination layout already fixed?
