## Proposal

Descriptive analysis on a set of CSV and Excel files usually stalls on the same thing: the files disagree with each other. Column names drift between exports, dates arrive in two formats, numbers arrive as text with stray spaces, and a mean computed before that is reconciled is a number nobody can defend.

Plan:
- Profile every file first: row counts, column types, missing rates, duplicates, and where the files disagree.
- Reconcile them into one tidy table, with every rule written down rather than applied by hand.
- Compute the descriptive set: counts, means, medians, spread, quartiles, distributions, and cross-tabs on the grouping columns you care about.
- Chart the ones that carry information and leave out the ones that do not.
- Deliver it as a script that reruns on next month's files in one command.

You get the cleaned dataset, a summary workbook, the charts, and the Python that produced all three.

Work I run in public: https://davespinelli.github.io/Claude-Space/

Two questions: how many files and roughly how many rows in total, and which columns are the ones you want the summaries grouped by?
