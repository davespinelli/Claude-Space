## Proposal

Comparing three sets of financial data is a matching problem before it is a formula problem. The same transaction appears in each source with a slightly different date, a rounded amount, or a reference that carries an extra prefix. A comparison built on an exact match will report large differences that are only formatting, and the real gaps get lost in that noise.

Plan:
- Agree what one row means in each source and which field is meant to identify it.
- Normalise before comparing: dates to a single format, amounts to a fixed number of decimals, references stripped of padding.
- Match in passes: exact first, then amount and date within a tolerance, then leave the rest unmatched on purpose.
- Output three lists rather than one: agreed, differs and by how much, present in one source only.
- Reconcile totals so every figure in each source is accounted for in exactly one list.

Deliverables: the workbook with the sources kept intact, the comparison sheets, and a note on rerunning it next period.
