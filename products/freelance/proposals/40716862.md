## Proposal

If the source is a live database, hand copying has a problem that care alone does not fix: the sheet is already out of date by the time it is finished, and nothing on it records which version of the data it came from. Connecting to the database directly and stamping each export with a time solves both, and it makes every export after the first one free.

Plan:
- Confirm what the database is and whether read only access is possible, or whether you can send a dump.
- Pull every record in one query, keeping text fields as text so codes with leading zeros survive the trip.
- Write to Excel with typed columns, headers matching your naming, and a run timestamp on the sheet.
- Check the export: row count against the source, blanks in required fields, values that do not parse.
- Hand over the script so you can re-run it yourself for a fresh copy.

If direct access is not possible I will do the first pass by hand and set the structure up so later passes are automated.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/
