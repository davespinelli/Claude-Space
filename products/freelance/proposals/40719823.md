## Proposal

A folder of customer emails is rarely one customer per email. The same person turns up three or four times with a new phone number, a different spelling of the company name, and a reply chain that repeats the earlier message underneath. So the real decision is which value wins, and the sheet is only worth trusting if it can show where each field came from.

Plan:
- Read the folder directly, whether it is .eml, .msg or an mbox export, rather than opening each message by hand.
- Pull name, company, email, phone and your other columns from the body and the signature block.
- Collapse duplicates to one row per customer, keeping the most recent value and noting what it replaced.
- Add a source column linking each row to its email, plus a count check: emails in, rows out, and any I could not parse.
- Return anything ambiguous as a short review list instead of guessing at it.

Deliverables: the spreadsheet, the exception list, and the script, so the next folder takes minutes.
