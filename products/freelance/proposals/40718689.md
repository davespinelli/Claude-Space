## Proposal

Four to seven sheets kept up to date by hand drift apart from each other. The same customer or product ends up spelled two ways across two sheets, and the totals stop agreeing without anyone noticing. So before keying anything I would fix the shape of the sheets: one place for each list, consistent typed columns, and a check that ties the sheets together.

Plan:
- Review the current sheets and list where the same value is held in more than one of them.
- Set typed columns and validation lists so text, numbers and dates cannot be entered inconsistently.
- Key the current backlog of updates, keeping codes as text so leading zeros survive.
- Add a check tab that shows row counts, totals and any value that appears in one sheet but not the other.
- Write down the update routine so the next round takes minutes.

You receive the maintained workbook, the check tab, and a one page note on the routine.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: where does the new data arrive from each time, and how often do the sheets need updating?

David
