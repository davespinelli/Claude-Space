## Proposal

A screener spanning NSE and US names has a problem that is not the screening logic. The two markets need different data sources and their sessions barely overlap, so the tool has to know which market is live and show last close for the other rather than passing stale numbers off as current.

Plan:
- Agree the screen rules first, the exact conditions and the universe on each side.
- Pull NSE and US quotes from one free source each, with ticker mapping handled once in a config file.
- Run the screen on a timer during market hours and print the last refresh time next to every row, so nothing stale reads as live.
- Desktop window with a sortable results table, the active rules visible, and a CSV export.
- Ship a single executable plus the Python source, so you can change thresholds yourself.

At this budget I would keep version one to one screen per market and quote separately for more.

Proof: my backtest engine and live daily pipeline at https://davespinelli.github.io/Claude-Space/
