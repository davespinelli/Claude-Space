## Proposal

You want a web app where a model writes analysis scripts against a user's data. The hard part is not the prompt, it is what happens after generation: generated code that references a column that does not exist, code that runs for ten minutes on a large upload, and code you cannot safely execute on your own server without isolating it first.

Plan:
- Build the upload and profiling step so the model is given the real schema, types and sample rows, not a guess.
- Generate the script, then run it in a sandboxed worker with a time and memory limit.
- Feed execution errors back for one automatic repair attempt before showing the user a failure.
- Show the script, the output and the chart together, with the script downloadable.
- Ship with auth, per user history, usage limits and a README for deployment.

You receive the running application, the source, and deployment instructions.
