## Proposal

You have a large set of numeric CSV files that need cleaning. With numeric data the damage is usually invisible: thousands separators that turn a number into text, a stray unit suffix, minus signs written as a dash character that does not parse, and empty cells that quietly become zero in whatever tool reads them next. Cleaning by hand fixes the file you looked at, not the next one.

Plan:
- Profile every file first and report what is actually wrong per column, with counts.
- Write a Python cleaning script with a rule per column: type, range, missing value handling, units.
- Flag outliers and impossible values for your decision instead of silently correcting them.
- Run it across the full set and produce a before and after summary per file.
- Deliver the cleaned CSVs plus the script so future files can be run through it.

You receive the cleaned files, the script, and the profiling report.

Public example of my data pipelines: https://github.com/davespinelli/Claude-Space

Two questions: how many files and roughly how many rows in total, and should missing values be left blank or filled?
