## Proposal

The hard part of a "stream of operational and campaign data" is not the reporting, it is that the stream keeps changing shape. A new campaign appears, a column gets renamed, and last month's workbook quietly breaks. So I build the refresh, not just the report.

Plan:
- Map your current sources and agree the handful of numbers the report actually has to answer.
- Build a Python ingest that normalises each source into one clean table, with a schema check that fails loudly instead of producing wrong totals.
- Generate the Excel report itself: summary sheet, per campaign detail, month over month comparison, formatted and ready to send.
- Add a one command refresh so a new drop of data regenerates everything in seconds.
- Document the whole thing in a short README so it is not dependent on me.

You receive the workbook, the ingest scripts, and the refresh instructions.
