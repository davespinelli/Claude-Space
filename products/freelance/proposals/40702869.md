## Proposal

Income and expenses, departmental budgets and whatever else is in the pile rarely share one shape. Departments name the same cost two ways, one file splits the year across twelve columns while another holds a single annual figure, and income sits at a different level of detail from spend. Typed straight into one sheet, the totals stop tying back to the source and nobody can say which file the gap came from.

Plan:
- Agree one line schema first: period, department, category, budget, actual, so every source lands in the same shape.
- Map each source's columns to that schema once and keep the mapping visible for you to check.
- Enter each line with a reference back to the file it came from.
- Reconcile every source's own total against the lines I transferred from it, which catches a missed block immediately.
- Flag anything that does not fit the schema rather than forcing it into the nearest column.

You get the combined workbook, the mapping sheet, per file reconciliation and a queries list.

Proof of how I work: https://davespinelli.github.io/Claude-Space/
