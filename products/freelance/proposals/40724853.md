## Proposal

Time sensitive batches are where the checking pass is the first thing dropped, and re-reading your own typing is the weakest check there is, because the eye repeats the mistake it made the first time. I would rather build the check into the entry than promise to be careful.

Plan:
- Confirm the column layout and the rules for blanks and ambiguous values before starting.
- Enter in source order, one pass, keeping the source reference against every row.
- Verify by an independent route: totals and counts per block against the source, not by re-reading.
- Apply validation to the columns with a fixed shape, dates, codes and amounts, so a bad value shows at once.
- Send the first block early, so the layout is agreed before the whole batch is keyed.

Deliverables: the workbook, a query list for anything unreadable, and a short note on what was checked and how.

Proof: https://davespinelli.github.io/Claude-Space/
