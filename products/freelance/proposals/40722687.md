## Proposal

Several batches into one workbook is the part that needs a decision before any typing starts. Batches collected separately rarely share a layout, so merging them produces rows that are one record written two ways: a trailing space, a company name with and without Ltd, a phone number with and without the country code. Which of those counts as a duplicate is your call, not something a de-duplicate button should decide.

Plan:
- Review a sample of each batch first and agree one column list that all of them map onto.
- Agree the matching rule in writing, which fields make two rows the same record and which value wins.
- Enter every batch with a source column, so no row becomes anonymous after merging.
- Normalise per column: one type, one date format, numbers stored as numbers, trailing spaces removed.
- Run a check pass for duplicates, blanks and wrong types, and send it with the draft.

Deliverables: the single workbook, the duplicate and exception report, and a one page note on the column rules.
