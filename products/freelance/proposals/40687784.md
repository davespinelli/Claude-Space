## Proposal

Getting Word and PDF text into Excel accurately is the whole job. Doing it by hand across a collection of files is exactly where transcription errors creep in, especially with numbers and with anything that runs across a page break.

Plan:
- Look at a few sample files first and confirm which fields map to which Excel columns.
- Extract with Python: python-docx for the Word files, pdfplumber for the PDFs, handling both flowing text and tables.
- Run automated checks on the output: field counts per document, missing values, and values that do not match the expected format.
- Review every flagged item by hand, so the final sheet is verified rather than just generated.
- Deliver one consistently formatted Excel workbook, plus a tab listing anything ambiguous with its source file and page.

If any files turn out to be scanned images rather than text, I will tell you before starting, since that changes the method.

You receive the workbook and the extraction script for future batches.
