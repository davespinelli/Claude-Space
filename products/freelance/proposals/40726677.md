## Proposal

Mixed Word and Excel files are awkward because the numbers you want to analyse are sitting inside prose and tables that were laid out for reading, not for computing. Converting them by copying the visible text usually loses the thing that made the number meaningful, which row or period it belonged to. The step that matters is deciding, before any conversion, what one row of the final table represents.

Plan:
- Agree the shape of the output table first: what a row is, and which columns it carries.
- Pull the tables out of the Word documents with their headers and context intact.
- Merge the Excel content into the same structure, reconciling different column names.
- Keep the images separately, linked to the row they belong to, rather than dropping them.
- Run the analysis you need on the combined table and put it in a summary tab.

Deliverables: the combined workbook, the analysis tab, and a note on anything that could not be mapped.
