## Proposal

The failure mode on an admin bot is not missed spam, it is the false positive. A regular member gets muted for posting a link, nobody can tell why, and you do more work than before. So every action needs a written reason and a one-step reversal, and the rules need to be readable without opening the code. Rate limits matter too: a bot answering every join in a burst gets throttled and looks broken.

Plan:
- List the actions to automate and the exact condition for each, before any code.
- Build on python-telegram-bot with the rules held in a config file you can edit.
- Run the first week in report only mode, where the bot logs what it would do and acts on nothing.
- Log every action with the message id, the rule that fired and a command to undo it.
- Deploy on a scheduled host with restart on failure, so it survives without your machine.

You get the bot, the rules file, the action log and a runbook.
