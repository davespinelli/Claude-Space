## Proposal

A watched folder script is easy to write and easy to get wrong. The real requirements are what happens when a file arrives half written, when the same file arrives twice, and when a row fails validation at 2am with nobody looking.

Plan:
- Watch the folder with a stability check, so a file is only picked up once the write has finished.
- Process with pandas, validate each row against rules you define, and move every file to processed or failed rather than leaving it in place.
- Write a verification report per run: rows in, rows out, rows rejected and the reason for each.
- Log to a rotating file and exit with a non zero code on failure, so a scheduler or service can alert you.
- Ship pytest coverage on the validation rules, a README, and a config file so thresholds are not buried in the code.

You receive the script, config, tests and README, packaged to run as a scheduled task or a service.
