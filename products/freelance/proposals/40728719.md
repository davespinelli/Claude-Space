## Proposal

The summarising is the easy half of this one. BSE and NSE push hundreds of announcements a day and most are routine: trading window closures, newspaper copies, the same PDF filed twice. Send all of it to a model and you get a long digest nobody reads and a cost that scales with the noise. The filter that runs before the model is what decides whether the output is worth opening.

Plan:
- Pull the daily announcement feed for your companies and keep a local record so nothing repeats.
- Filter on category and keyword first, so only material filings reach the model.
- Summarise each filing against its own text only, with the source link on every line.
- Deliver one dated digest, grouped by company, in the order you want to read it.
- Schedule it on GitHub Actions so it runs after market close without your machine on.

Deliverables: the script, the watchlist and filter configuration, the scheduled daily run, and a README.
