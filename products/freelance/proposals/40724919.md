## Proposal

Entering through a web form rather than an import changes what can go wrong. Each save is a commit with no batch undo, so a field the form quietly truncates, or a dropdown with no match for what the image says, becomes a record nobody finds again later. The other failure is interruption: a session that expires halfway through a form leaves a half record that looks like a real one.

Plan:
- Do ten records first and confirm the field mapping with you before the rest.
- Keep a local sheet as the working copy, so every submitted record has a source row and a status.
- Record the image reference against each entry, so any field traces back to the picture it came from.
- Treat unreadable values as a query list, never as a guess or a silent blank.
- Reconcile at the end: count in the database against count in the sheet, plus a spot check.

Deliverables: the records entered, the tracking sheet and the query list.
