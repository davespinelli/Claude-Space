## Proposal

Either Microsoft Excel or Google Sheets is worth settling before a single row gets typed. The two look interchangeable and are not: conditional formatting rules, data validation dropdowns and custom number formats all cross over partially or not at all, so a sheet built in one and delivered in the other arrives looking half finished and has to be redone. I build in whichever one you actually work in day to day.

Plan:
- Confirm the target tool, the column list and one example row you consider correct.
- Enter the data with one type per column, numbers as numbers and dates in a single format.
- Apply the styling through rules and named styles rather than cell by cell, so it holds when rows are added later.
- Put validation on the columns other people will type into, so the shape cannot quietly break.
- Run a check pass on counts, duplicates and blanks, and list anything ambiguous instead of guessing.

You get the finished workbook and a short note on how the rules are set up.
