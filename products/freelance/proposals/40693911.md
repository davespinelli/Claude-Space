## Proposal

Cleaning a raw workbook by eye is the part that gets redone six months later, because nobody can see what was changed or why. The useful output is not just a tidier file, it is an agreed list of correction rules applied the same way to every row, plus a record of what moved.

Plan:
- Profile the workbook first and give you a short list of the actual error types found, with counts, before touching anything.
- Agree a rule per error type: date formats, number and text mismatches, stray characters, duplicates, inconsistent spellings.
- Apply the rules with a script so the same input always gives the same output.
- Flag rather than guess anything ambiguous, and return those rows to you as a short review list.
- Deliver a change log showing the original value, the new value and the rule that changed it.

You receive the cleaned workbook, the change log, the review list, and the script so you can rerun it on the next batch.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: roughly how many rows and columns, and should corrected rows stay in place or be kept on a separate sheet?
