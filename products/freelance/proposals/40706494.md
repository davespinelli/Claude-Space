## Proposal

The usual problem with a first analysis is not the statistics, it is that the finished notebook cannot be re-run. A column got fixed by hand, a filter was applied once and forgotten, and when new data arrives the numbers do not reproduce. Beginner friendly should mean you can run it yourself next month and get the same answer.

Plan:
- Load your data as it arrives, with the cleaning written as code rather than done by hand.
- Profile it first: row counts, missing values, duplicates and anything that looks wrong, reported before any conclusions.
- Run the analysis the question needs, with each step in its own cell and a plain sentence explaining what it does.
- Chart only what carries the finding, labelled so it stands alone.
- Write the summary in plain language, with the caveats stated rather than buried.

You get the notebook, the cleaned data, the charts and a short written summary.
