## Proposal

Regular entry work fails differently from a one off job. The first batch is usually fine. The drift starts around batch four, when a slightly different source arrives and gets handled a slightly different way, and by the end of the month the sheet holds two conventions for the same field.

Plan:
- Agree the sheet layout and one written convention per field before the first batch.
- Enter each batch against that convention, with a date and source marked on every row.
- Run the same check pass each time: duplicates, blanks in required fields, values that break their column type.
- Return questions as a short list per batch instead of guessing at an unclear record.
- Keep a running note of new cases and how we decided them, so batch twenty matches batch one.

You get the maintained Google Sheet or workbook, the conventions note and a queries list per batch.
