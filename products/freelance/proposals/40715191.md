## Proposal

Pulling the records is rarely the hard part with several databases. The hard part is that each source names the same field differently, some carry fields the others do not, and when one changes its page layout the scraper keeps running and quietly returns blanks. A workbook that looks full but is missing a third of one source is worse than no workbook.

Plan:
- Agree the target columns first, then map each source's fields onto them.
- Write one small extractor per source, all of them writing into that same layout.
- Stamp every row with its source and the date it was pulled, so anything can be traced back.
- Validate on delivery: row count per source, required fields present, duplicates flagged rather than silently dropped.
- Hand it over as a script, so a refresh later is one command instead of a repeat of this job.

I work from publicly accessible pages only, nothing behind a login, a paywall or a captcha.

You get the Excel workbook, the per source count report and the code.
