## Proposal

The hard part of story-idea-to-finished-film is not any single model call, it is continuity. Generate scenes independently and your lead changes face between shot four and shot five, the voice drifts, and the cut no longer reads as one film. So the pipeline has to carry a fixed character and style reference through every stage rather than re-describing it each time.

Plan:
- Idea to beat sheet to shot list, as structured JSON, so every later stage reads the same script rather than free text.
- Lock character and style references once, then pass them into every image or video call.
- Voice per character from one fixed voice id, timed against the shot list.
- Assemble with ffmpeg: shots, dialogue, music bed, titles, one MP4 out.
- Re-run any single scene without rebuilding the film.

You receive the Python pipeline, the config, a README, and one finished short film end to end.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: which generation APIs do you already pay for, and what runtime counts as complete for you, three minutes or thirty?
