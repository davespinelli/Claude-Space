## Proposal

Sales exports arrive with the same short list of problems every time. Dates stored as text in two different formats, amounts carrying currency symbols and thousands separators so they sum to zero, merged header rows that break any pivot, and trailing spaces that split one customer into three rows that look identical. Tidying that by hand works once and drifts again with next month's export.

Plan:
- Profile the file first and send you the list of problems found before I change anything.
- Fix the types properly: real dates, real numbers, consistent text, no hidden characters.
- Standardise the names that should match, with the mapping written down rather than applied by eye.
- Lay it out as one clean table, one row per record, ready to pivot.
- Deliver it as a script so next month's file is one command rather than a repeat of this job.

You get the cleaned workbook, the mapping sheet and the script that produced both.

Work I run in public: https://davespinelli.github.io/Claude-Space/

Two questions: how many rows and how many files, and do you want the original kept as a sheet beside the cleaned one?
