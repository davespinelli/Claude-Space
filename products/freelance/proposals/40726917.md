## Proposal

When records are copied from several sheets into one master, the errors that survive are almost never typos. They are alignment. One sheet has an extra header row or its columns in a different order, so the values land under the wrong headings, and everything below a skipped row sits one line off. Nothing flags it, because a copied value is valid wherever it lands.

Plan:
- Match each source sheet to the master by header name rather than by column position, so a reordered or extra column cannot shift a row.
- Move the records by script, so the same run repeats identically when the next sheet arrives.
- Reconcile per sheet: row counts in and out, and column sums compared against the source.
- List every record that did not match cleanly instead of placing it on a guess.
- Carry types across, so dates and numbers do not arrive as text.

Deliverables: the master file, the exception list, and the script.
