## Proposal

Pulling plain text out of a PDF sounds like one step, and it has one failure worth naming up front. A PDF stores characters with positions, not paragraphs, so a two column page comes out interleaved: half a line from the left column, half from the right, arriving in the cell as nonsense. Reading order is most of the work, and it is why output from a generic converter usually has to be redone.

Plan:
- Check whether the files carry a text layer or are scans, since scans need OCR and a different accuracy claim.
- Extract with reading order resolved from the page layout rather than raw character order.
- Write one row per file or per page, with the filename in a column so any text traces back.
- Produce a per file status so no document is silently absent from the sheet.
- Hand over the script so you can rerun it on the next batch yourself.

You get the Excel file, the script with a short README and the status list.

Proof: https://davespinelli.github.io/Claude-Space/
