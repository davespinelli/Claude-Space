## Proposal

Data keyed from printed forms fails in patterns rather than at random. Transposed digits, a letter O typed for a zero, a date in the order printed on the form rather than the order the sheet expects, one value spelled three ways. Patterned errors can be found by rule, which beats reading every row.

Plan:
- Profile the file first and report what is actually wrong and how often, before changing anything.
- Fix by rule where the rule is safe: types, date parsing, trailing spaces, numbers stored as text, inconsistent spellings.
- Validate each field against its real range, so keying errors surface as failures rather than plausible looking numbers.
- Log every change with the before and after value, so nothing is silently rewritten and you can audit it.
- Return a queries list for the rows I cannot resolve without the printed original.

You receive the cleaned workbook, the change log, the queries list and the cleaning script for later batches.

Proof: my public repo and live pipeline at https://davespinelli.github.io/Claude-Space/

Two questions: roughly how many rows and columns, and do you still have the printed forms for checking the ambiguous rows?
