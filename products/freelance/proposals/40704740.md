## Proposal

The template is where these jobs go wrong. A column that looks obvious on the first page turns out to be missing on the thirtieth, or worded so differently that two readings are defensible. If that gets filled in silently, you end up with one column holding two different meanings and no way to tell which rows are which.

Plan:
- Run the first ten links, fill the template, and send it back for your check before doing the rest.
- Ask about cases the template does not cover instead of filling a best guess.
- Keep the source link and the capture date on every row so any value can be verified later.
- Copy only what is publicly visible on the page. No logins, and no personal contact details.
- Spot-check a fixed share of finished rows against the live pages and report the error rate.

You get the completed template, the list of queries and how each was resolved, and the spot-check result.

A pipeline I run publicly: https://davespinelli.github.io/Claude-Space/

Two questions: roughly how many links are there? What should I do when a page simply does not carry one of the template fields?
