## Proposal

Names and mailing addresses have a failure mode that proofreading misses: a wrong postcode or a swapped street number reads fine on screen and only shows up when the mail comes back. Your source files are already digital, so the text can be pulled from them rather than retyped, which removes that whole class of error.

Plan:
- Take one file of each kind you have, PDF, Word, CSV or email, and agree the column layout.
- Extract the text directly from the files instead of keying it, so spellings match the source exactly.
- Split each address into its own columns: line 1, line 2, city, state or county, postcode, country.
- Flag rather than guess. Anything with a missing postcode or an unreadable line goes to a review tab for you to confirm.
- De-duplicate on name plus postcode so one customer does not appear twice.

You receive the Excel workbook, the review tab, and a short note on what was flagged and why.
