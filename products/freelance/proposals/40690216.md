## Proposal

Financial workbooks usually do not need more macros, they need fewer and better ones. The recurring problems are a macro that assumes a fixed row count, one that hardcodes a sheet name someone later renamed, and no way to tell whether last month's run actually finished. Reliable is the word in your brief and it is the right target.

Plan:
- Walk the existing workbooks and list every manual step worth automating, ranked by time saved.
- Rewrite the automation against named ranges and tables rather than fixed cell addresses, so it survives new rows.
- Add input validation before any calculation runs, with a clear message when a source sheet is missing or malformed.
- Include a run log sheet: when it ran, what it processed, what it changed.
- Keep the code commented and modular so another person can maintain it.

You receive the updated workbooks, the macro source, and a short user guide.

Example of my finance automation, public and tested: https://github.com/davespinelli/Claude-Space

Two questions: which manual steps cost you the most time now, and must this stay VBA or is a Python side tool acceptable?
