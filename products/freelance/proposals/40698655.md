## Proposal

The word in your brief that matters is refresh-ready. Most Excel reports work once and then break the following month, because the lookups point at fixed ranges and a pasted row of new data lands outside them. The report then shows stale numbers rather than an error, which is the worst failure mode.

Plan:
- Convert the raw sheet to a structured table so new rows are picked up automatically.
- Rebuild the lookups against that table, using INDEX and MATCH or XLOOKUP rather than column numbers that shift when someone inserts a field.
- Build the pivots on the table, so refresh is one button and not a rebuild.
- Add a small checks block that shows row counts and unmatched keys, so a bad refresh is visible immediately.
- Format the output sheet for printing and sharing, with the raw data kept separate and untouched.

You receive the workbook with raw, working and report sheets, plus a short note on the monthly refresh steps.
