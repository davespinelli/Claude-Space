## Proposal

The split that decides this job is whether your PDFs carry a text layer or are scans. Text-layer files can be read straight out of the file and checked against themselves. Scans have to be recognised, which means an error rate that has to be measured rather than assumed. Word files are exact either way.

Plan:
- Sort every file into text-layer PDF, scanned PDF or Word, and tell you the counts before any work starts.
- Extract directly from the text-layer and Word files, which carries no typing error at all.
- Recognise the scanned pages twice and flag every cell where the two passes disagree.
- Normalise dates, numbers and text into the single column layout you want.
- Review the flagged cells and a sample of the rest before handover.

You receive one consolidated Excel workbook, a sheet listing what was flagged and corrected, and the extraction script so you can add later files yourself.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/

Two questions: roughly how many files in total, and do you have a target column layout already or should I propose one?
