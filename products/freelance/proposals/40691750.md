## Proposal

You collect information in a workbook and then retype it into a web form. The retyping is the annoying part, but the real cost is the silent failure: the script or the person submits a row, the page throws a validation error or just loads slowly, and nobody notices the record never landed until someone goes looking for it.

Plan:
- Map your sheet columns to the form fields, including dropdowns, dates and any conditional fields.
- Build a Playwright script that fills and submits one row at a time and waits for the confirmation the page actually renders, not a fixed sleep.
- Write the outcome back to the sheet: submitted, timestamp, or the exact error text.
- Retry only the failed rows and skip anything already marked done, so a rerun is safe.
- Package it as a one command run with a README.

You receive the script, run instructions, and a supervised test run on rows you pick before it touches the rest.
