## Proposal

Support bots get replaced rather than upgraded because nobody can show they improved. The prompt gets rewritten, a few test questions look better, and the same complaints keep arriving. Without a fixed set of real questions scored before and after, an upgrade is just a different set of wrong answers.

Plan:
- Pull 50 real conversations from your logs and mark what the correct answer was for each.
- Score the current bot against that set, so we start from a number rather than an impression.
- Upgrade where the score says: retrieval over your own help content, clearer fallbacks, and a handoff to a human when confidence is low.
- Re-score against the same frozen set and report the before and after side by side.
- Leave the test set and the scoring script in the repo so the next change can be measured too.

You get the upgraded bot, the frozen test set, the scoring script and the before and after numbers.
