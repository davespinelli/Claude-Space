## Proposal

Reports that mix commentary with figures are where hand keying goes wrong quietly. The tables sit in a slightly different shape on each page, and a figure typed one column across still looks perfectly reasonable, so nothing ever flags it.

Plan:
- Pull the text layer out of each PDF so the figures come from the file itself rather than from retyping.
- Map each report's tables onto one consistent column layout in your workbook.
- Check every extracted total against the total printed in the report and flag the mismatches.
- Keep narrative fields in their own columns so text and numbers stop fighting each other.
- Review the flagged pages by hand and record what was changed and why.

You receive the Excel workbook, a check sheet listing every total that did not reconcile, and the extraction script so next quarter's reports take minutes instead of days.

Proof: my public repo and live dashboard at https://davespinelli.github.io/Claude-Space/
