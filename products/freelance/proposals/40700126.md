## Proposal

Word documents that look identical to a reader rarely are underneath. One file has the figures in a table, the next has the same figures in a sentence, and a third repeats a field in a header. Typed by hand that is slow and inconsistent; read by script it is fine, as long as the odd ones out are flagged rather than guessed.

Plan:
- Take a handful of documents first and agree exactly which fields come out and what each one is called.
- Script the extraction across tables, paragraphs and headers, so the same field is found wherever it sits.
- Send anything the script is not confident about to a review list instead of writing a wrong value.
- Type the review list by hand, which is usually a small fraction of the batch.
- Check the result: row count against file count, required fields present, numbers as numbers and dates as dates.

You get the filled spreadsheet, the review list showing what was manual, and the script so a future batch is a rerun.

Proof: my public repo and live pipeline at https://davespinelli.github.io/Claude-Space/
