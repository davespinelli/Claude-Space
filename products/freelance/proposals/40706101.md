## Proposal

The Streamlit part of this is a day of work. What decides whether the recommender is any good is the rule base behind it and where the laptop data comes from, since a confident recommendation drawn from a catalogue that went stale six months ago is worse than no recommendation at all. Most demos of this kind hard code twenty machines and fall over the first time someone asks for something outside them.

Plan:
- Agree the question set: use case, budget, portability, screen, battery life, and any hard requirements.
- Put the rules in a readable table with a weight per criterion, rather than burying the logic in code.
- Score every laptop in the catalogue, return the top three, and show why each one scored where it did.
- Load the catalogue from a spreadsheet you control, so adding or retiring models needs no developer.
- Deploy on Streamlit Community Cloud with the config and a short guide for updating the data.

You get the app, the catalogue sheet, the rule and weight table, and the live deployment.

A dashboard I run publicly: https://davespinelli.github.io/Claude-Space/

Two questions: do you already have a laptop dataset, and roughly how many models should it cover at launch?
